Lesson 105 -- Node Class -//



# Khái niệm 
	Một Node là một đơn vị cấu trúc dữ liệu cơ bản, có thể liên kết với các Node khác để hình thành cấu trúc lớn hơn như:
	
		class Node {
			T value;
			Node next;
		}
	
	Linked List
	Tree (Binary Tree, Trie, B-Tree)
	Graph (DAG, Cycles, v.v.)



# ⚙️ 2. Các yếu tố kiến trúc trong Node 
	
	Thành phần			 		| Vai trò 							| Kiến trúc liên quan
	value 					| Dữ liệu hiện tại 						| Payload / Entity
	next 					| Liên kết với phần tử tiếp theo 		| Pointer / Edge
	left, right 			| Cho cây nhị phân				 		| Tree traversal
	neighbors 				| Cho Graph 					 		| Network Topology
	parent					| Quan hệ ngược					 		| Backtracking, recursion
	children (List<Node>)	| Quan hệ forward				 		| Hierarchy, Composite pattern


Kết luận: Node = phần tử tự mô tả trong một cấu trúc phức tạp.





# 🧠 3. Tư duy như một kiến trúc sư phần mềm
	


	## 🔸 Node như là một Actor (tác nhân độc lập) 
		
		-	Trong hệ thống phân tán, bạn có thể coi mỗi Node là:
		-	Một microservice (có data, biết nói chuyện với người khác)
		-	Một unit xử lý trong DAG (như trong airflow hoặc n8n)
		-	Một actor (trong Actor Model - Akka, Erlang)



	## 🔸 Node là abstraction của mọi thứ kết nối được
		
		Context					 | Node là gì
		DOM (HTML)			 | Mỗi element là một DOM node
		React Fiber			 | Mỗi phần tử giao diện là 1 node với state
		Blockchain			 | Mỗi peer là một node trong network
		Kubernetes			 | Mỗi máy ảo là một node trong cluster
		Graph 				 | Mỗi thực thể là 1 node (User, Page, Post, ...)
		


# 🧰 4. Các dạng Node phổ biến

		Kiểu Node									 | Mô tả
		LinkedList Node 						| Trỏ đến next
		Tree Node  								| Có left/right hoặc list of children
		Graph Node 								| Có neighbors
		Doubly Node 							| Có cả next và prev
		Trie Node 								| Dùng trong từ điển prefix, text search
		N-ary Tree Node 						| Mỗi node có nhiều children
		AST Node (Abstract Syntax Tree) 		| Biểu diễn mã nguồn như 1 cây logic	




# 🎯 5. Kiến thức liên quan cần học

	## Data Structure & Algorithms
		→ Cách tổ chức và xử lý tập hợp các Node để tối ưu:
			- Tìm kiếm: DFS, BFS, Binary Search Tree
			- Sắp xếp: Merge, Quick Sort
			- Định tuyến: Dijkstra, A*	


	## Design Pattern 
		
		- Composite pattern
		- Iterator pattern
		- Visitor pattern (duyệt node kiểu AST)


	## Functional programming

		-	Xử lý node đệ quy, immutable
		-	Lambda trên node list


	## Distributed systems (Hệ thống phân tán )
		-	Node là actor, là peer trong cluster
		-	Gossip, Raft, Paxos: node tham gia đồng thuận

	

# 💡 6. Tư duy system-level về Node 
	
	Node là gì ở cấp system? 							| Nghĩa kiến trúc
	Thành phần độc lập 								 | Có thể test riêng, deploy riêng
	Có quan hệ với các phần tử khác					 | Không đứng 1 mình
	Có trạng thái (state) và hành vi (behavior) 	 | Tương tác với hệ thống
	Có thể scale theo chiều ngang 					 | Giống cluster nodes
	Có thể bị lỗi riêng biệt 						 | Fault-tolerant system




# 📌 Kết luận 
	
	Node là một trong những khái niệm giản dị nhưng quyền lực nhất trong kiến trúc phần mềm. Là viên gạch cơ bản để bạn xây dựng:

		-	Linked List → FIFO Queue
		-	Tree → DOM, UI hierarchy, Binary Index
		-	DAG → Task pipelines
		-	Graph → Social network, Microservice communication
		-	Cluster → Distributed system
