Lesson 70 -- java.base -//


# Khái niệm 
	Trong Java 9, hệ thống module được giới thiệu (JPMS - Java Platform Module System), và java.base là module lõi của JDK 
		- java.base chứa các API cơ bản nhất mà mọi ứng dụng Java cần 
		- Tự động được import vào tất cả các module, không thể bị loại bỏ 
		
		➡ Không có java.base thì JVM không thể hoạt động 
		
# java.base chứa gì 
		
		Module java.base chứa các package cốt lõi như : 
		
			Package							Chức năng
			java.lang					String, Math, Object, System, Thread...
			java.util					Collections, List, Set, Map, Date, Optional...
			java.io						Input/Output Streams, File, Reader/Writer...
			java.nio					NIO (Non-blocking IO), Buffer, Charset...
			java.net					Networking API (HTTP, URL, Socket)...
			java.security				API bảo mật, mã hóa, hash...
			java.time					Date/Time API (Java 8+)
			java.math					BigInteger, BigDecimal (số lớn, số chính xác cao)


		💡 Mọi class cơ bản của Java đều nằm trong java.base.


# java.base hoạt động thế nào ? 
	
	🔹 a) không cần requires java.base 
		- Khi tạo module, bạn không cần requires java.base vì nó được import mặc định  
		
				module mymodule {
					requires java.sql;  // Chỉ cần khai báo các module khác ngoài java.base
				}

	
	🔹 b) java.base không phụ thuộc vào module nào khác 
		- Tất cả các module khác trong JDK đều phụ thuộc vào java.base 
		- Nhưng java.base không phụ thuộc vào bất kỳ nhóm module nào khác 
	
	🔹 Ví dụ Dependency Tree của java.sql
	
			$ jdeps --module java.sql
			java.sql -> java.base
			java.sql -> java.logging

			➡ java.sql cần java.base để hoạt động.


# Tại sao  java.base quan trọng trong hệ thống lớn 
	
	## ✅ Giảm kích thước ứng dụng 
		- Trước Java 9 , tất cả các JAR của JDK đều được nạp vào JVM 
		- Giờ đây, nếu ứng dụng không cần java.desktop, ta có thể bỏ module đó 
		
	## ✅ Tăng bảo mật và kiểm soát 
		- Trước đây, Java không thể kiểm soát code nào được truy cập vào package nào 
		- Bây giờ, module system ngăn chặn truy cập trái phép giữa các phần của ứng dụng 
	
	## ✅ Tối ưu hóa JVM và ứng dụng AI , Microservice 
		- Trong ứng dụng AI, Spring Boot , gRPC, Microservices, ta chỉ cần nạp các module cần thiết 
		- Hệ thống nhẹ hơn, tốc độ nhanh hơn
