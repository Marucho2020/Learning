Lesson 189 -- Collectors nâng cao -//


# 1. Collectors.toMap

	Biến Stream thành Map<K,V>.

Map<Integer, String> map = employees.stream()
    .collect(Collectors.toMap(Employee::getId, Employee::getName));


	⚠️ Senior point: phải để ý key collision (キー衝突).
	Nếu 2 Employee cùng id → IllegalStateException.
	Giải pháp: truyền merge function:

toMap(Employee::getId, Employee::getName, (oldVal, newVal) -> oldVal)

hoặc chọn theo rule (newVal ghi đè oldVal, hoặc concat).


# 2. groupingBy

	Giống SQL GROUP BY.
	Trả về Map<K, List<T>> hoặc với downstream collector → Map<K, SomethingElse>.
	Ví dụ: group theo department, rồi tính tổng lương:

Map<String, Integer> salaryByDept = employees.stream()
    .collect(Collectors.groupingBy(Employee::getDepartment,
             Collectors.summingInt(Employee::getSalary)));

⚠️ Senior point:

	groupingByConcurrent tối ưu parallel stream.
	Downstream collector có thể lồng → powerful như multi-level aggregation (多段集約).



# 3. partitioningBy

	Special case của groupingBy → key là boolean.
	Dùng khi rule chỉ có 2 trạng thái (二分).

Map<Boolean, List<Employee>> result =
    employees.stream().collect(Collectors.partitioningBy(e -> e.getSalary() > 1000));

	⚠️ Dùng partitioningBy thay vì groupingBy khi chỉ cần true/false để code clear.


# 4. joining

	Gom các String thành một chuỗi.
	joining(", ") = CSV output.

String csv = employees.stream()
    .map(Employee::getName)
    .collect(Collectors.joining(","));

⚠️ Senior point: joining có overload cho prefix/suffix, hữu ích khi xuất ra JSON-like string, CSV, log format.




# 5. reducing

	Collector thấp nhất, giống reduce() nhưng để trong collect.
	Dùng khi muốn full control.

	Ví dụ tính tổng lương:

int total = employees.stream()
    .collect(Collectors.reducing(0, Employee::getSalary, Integer::sum));

	⚠️ Senior point: reducing linh hoạt nhưng verbose. Thường thay bằng summingInt, counting… cho readable. Nhưng biết reducing là bắt buộc ở level Gold, vì nó cho thấy bản chất "monoid accumulation" (モノイド畳み込み).


# 6. Enterprise insight

	Trong enterprise system, Collectors = report generator.
		- groupingBy → thống kê nhân viên theo phòng ban, status, role.
		- toMap → build dictionary cache (id → object).
		- joining → tạo CSV export.
		- reducing → tính KPI, tổng lương, max/min salary.

	⚠️ Ở level senior: luôn nhớ Collectors ≈ SQL aggregation nhưng trong code. Chọn collector không chỉ để ra kết quả, mà còn để code readable, maintainable, scalable.


	## 👉 Tóm gọn kiểu senior:

		toMap: key-value dictionary.
		groupingBy: SQL GROUP BY.
		partitioningBy: boolean split.
		joining: concat string.
		reducing: tổng hợp tuỳ biến, hiểu được monoid pattern.
