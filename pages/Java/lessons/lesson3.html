Lesson 3 -- Java 11 Commands Overview -//

Các lệnh được sử dụng trong Java 11 

# 1. jdeps(Java Dependency Analyzer) 依頼関係
	## Công dụng :
		Lệnh này dùng để phân tích các dependencies (phụ thuộc) trong một ứng dụng Java. Nó kiểm tra mã nguồn hoặc file .class/.jar phụ thuộc vào các thư viện nào 
		
	## Ứng dụng : 
		- Kiểm tra ứng dụng có phụ thuộc vào các API nội bộ hoặc deprecated không 
		- Giúp tối ưu hóa ứng dụng bằng cách loại bỏ thư viện không cần thiết 
		
	## Cú pháp 
		jdeps <tên_file.jar hoặc .class >
			
			jdeps myapp.jar
			Kết quả : Liệt kê tất cả các module và packages mà myapp.jar đang sử dụng 
			
	
# 2. jlink(Java Linker )
	
	## Công dụng 
		Tạo một runtime image tùy chỉnh, bao gồm những module cần thiết cho ứng dụng của bạn. 
	
	## Ứng dụng : 
		Tối ưu hóa dung lượng của ứng dụng 
		Đóng gói ứng dụng kèm runtime để chạy độc lập, không phụ thuộc vào cài đặt JDK/JRE 
		
	## Cú pháp  
		jlink --module-path <path-to-modules> --add-modules <> --output <tên folder output>
		
			### Ví dụ 
				jlink --module-path $JAVA_HOME/jmods --add-modules java.base,java.sql --output mycustomjre
				
				Kết quả : tạo một runtime Java nhẹ với chỉ các module java.base và java.sql 


# 3. javap(Java Class File Disassembler )
	## Công dụng  : 
		Dùng để xem chi tiết bên trong file .class(bytecode). Nó giống như một công cụ giải mã file .class 
		
	## Ứng dụng : 
		Tìm hiểu cấu trúc bytecode của một class 
		Hỗ trợ debug lỗi liên quan đến complier 
		
	## Cú pháp 
		javap <tên class hoặc file.class> 
		
			Ví dụ : javap MyClass 
			
			Kết quả : Hiển thị cấu trúc class của MyClass, bao gồm các method, field, constructor 
			
	## Mở rộng 
		thêm option -c (hoặc gọi là thêm flag -c) để xem bytecode 
			javap -c MyClass 
			

# 4. jshell (Java Shell )
	## Công dụng : 
		Là một REPL(Read-Eval-Print Loop) cho Java, cho phép bạn chạy mã Java trực tiếp mà không cần viết trong file .java 
		
	## Ứng dụng : 
		- Thử nghiệm nhanh các đoạn code java 
		- Học Java hoặc kiểm tra ý tưởng code mà không cần tạo file 
			
	## Cú pháp 
		jshell
		
		# Ví dụ , giống như chạy 1 chương trình python thử nghiệm k cần tạo các class main phức tạp  
		jshell
		jshell> int x = 10;
		jshell> System.out.println(x + 5);
		15


Tóm tắt dễ nhớ:
Lệnh	Chức năng chính
jdeps	Phân tích dependencies của ứng dụng.
jlink	Tạo runtime Java tùy chỉnh, chỉ chứa các module cần thiết.
javap	Xem chi tiết bytecode bên trong file .class.
jshell	Chạy thử mã Java trực tiếp (REPL).
