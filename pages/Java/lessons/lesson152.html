Lesson 152 -- Collections -//


# 1. Kiến trúc tổng thể của Collections Framework

		- Collection: giao diện gốc, chứa List, Set, Queue
		- Map: giao diện riêng biệt, không kế thừa từ Collection
		- Hiểu phân loại cấu trúc dữ liệu:
		- List: ArrayList, LinkedList, Vector, Stack
		- Set: HashSet, LinkedHashSet, TreeSet
		- Queue: PriorityQueue, ArrayDeque
		- Map: HashMap, LinkedHashMap, TreeMap, WeakHashMap, ConcurrentHashMap

	🔍 Phải hiểu ưu/nhược điểm về thời gian truy xuất, bộ nhớ, và trường hợp áp dụng phù hợp

# 2. Complexity & Performance

	- ArrayList: O(1) get, O(n) insert/remove
	- LinkedList: O(1) insert/remove đầu/cuối, O(n) get
	- HashMap: O(1) get/put (bình thường), O(n) trong worst case
	- TreeMap / TreeSet: O(log n) với mọi thao tác → do dùng Red-Black Tree

	🎯 Khi design hệ thống lớn, phải chọn cấu trúc đúng với yêu cầu concurrency, memory, tốc độ.
	
	
# 3. Concurrent Collections 	
	
	- ConcurrentHashMap: chia segment, không bị block toàn bộ map
	- CopyOnWriteArrayList: hiệu quả khi đọc nhiều, ghi ít
	- BlockingQueue: dùng trong producer-consumer (LinkedBlockingQueue, 	ArrayBlockingQueue, DelayQueue…)
		
# 4. Comparator vs Comparable	
	
	Comparable: dùng để so sánh chính nó với object khác
	Comparator: dùng để tùy biến cách so sánh từ bên ngoài

	→ Phải hiểu rõ vì ảnh hưởng đến TreeMap, TreeSet, PriorityQueue, và sorting logic.
