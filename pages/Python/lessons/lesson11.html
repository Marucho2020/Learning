- Hàm id(value) 		// trả về ID của một biến (vùng nhớ ) của nó được lưu trong chương trình 
				// Giá trị được trả về là một số nguyên và không bị thay đổi trong suốt chương trình 
			a = 1 
			print(id(a))		// 140719436719016


	
- Toán tử là một phương thức  
		
		.__add__(1)		// tương tự như n + 1
		
					print(n.__add__(1))		// 70  -> kiểu dữ liệu nguyên thủy nên ko thay thế giá trị gốc khi không sử dụng 	n = n.__add__(1)

- Sự khác nhau giữ hash object và unhash object 

	Hash Object : là các kiểu dữ liệu nguyên thủy , String , Tuple , Bạn không thể thay đổi nội dung của nó 
					Do đó , Python sẽ xin đủ khoảng trống để lưu dữ liệu của bạn, không nhiều hơn cũng k ít hơn.
					Giúp không hoang phí bộ nhớ của bạn, Thế nên khi cộng thêm giá trị , Python không biết 
					nhét thứ bạn muốn vào chỗ nào nên nó sẽ -> TẠO MỘT VÙNG NHỚ MỚI ĐỂ LƯU TRỮ GIÁ TRỊ 
					--> GIÁ TRỊ ID SẼ THAY ĐỔI KHI SỬ DỤNG  += GIÁ TRỊ CỦA MỘT HASH OBJECT 
				_str = "String "
				_tup = (1 , )
				print(id(_str))			// 2354475739792
				print(id(_tup))			// 2354475334576
				_str += "Learn "
				_tup += (2 , )
				print(id(_str))			// 2354475822576        // ID vùng nhớ đã bị thay đổi 
				print(id(_tup))			// 2354475812416        // ID vùng nhớ đã bị thay đổi 
				print(_tup)				// (1, 2)


	

	Unhash Object : Là các kiểu dữ liệu Object như List , Class , Object ... Là một đối tượng động , có thể thay 
					đổi nội dung của nó , Python luôn xin dư bộ nhơ để chừa chỗ cho các giá trị có thể thêm vào
					vì vậy nó sẽ chiếm dụng nhiều hơn là hash object
