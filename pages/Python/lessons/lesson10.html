1.  TUPLE LÀ BẤT BIẾN (IMMUTABLE)
		TỨC LÀ SAU KHI TẠO RA MỘT TUPLE, BẠN KHÔNG THỂ THAY ĐỔI , THÊM, HAY XÓA CÁC PHẦN TỬ TRONG NÓ (Kiểu như final ấy nhỉ)
  
  - Được khai báo các giá trị trong dấu ()  và được phân cách bởi các dấu  ,  
  - Nếu tuple chỉ có một phần tử, bạn cần thêm dấu phẩy sau phần tử đó để phân biệt với phép toán nhóm(parentheses)
  - Sử dụng khi muốn dữ liệu không bị thay đổi trong suốt chương trình 
  - Tuple tốn it bộ nhớ hơn list, và do đó có thể hữu ích khi làm việc với các tập dữ liệu cố định hoặc lớn

3. Sử dụng trong unpacking

2. MỘT SÔ TOÁN TỬ VỚI TUPLE TRONG PYTHON 
	Các toán tử của Tuple giống với toán tử của chuỗi
	
	-  Toán tử +     
			tup = [1, 2]
			tup += ('how', 'kteam') 			// [1, 2, 'how', 'kteam']

	-  Toán tử * 	
			tup = tuple('kter') * 3  // ('k', 't', 'e', 'r', 'k', 't', 'e', 'r', 'k', 't', 'e', 'r')
				
		
	
3. Indexing và cắt Tuple trong Python //  tup = (1, 2, 'a', 'b', [3, 4])

  print(tup[1]) 			// 2 
  print(tup[-1])			//  [3, 4]
  

	tup[3]					// 'b'
	tup[1:3]				// (2, 'a')
	tup[:2]					// (1, 2)
	tup[2:]					// ('a', 'b', [3, 4])
	tup[::-1]				// ([3, 4], 'b', 'a', 2, 1)
  
 
4.Tuple lồng nhau 		Ma trận  	// tup = ((1, 2, 3), [4, 5])

			tup[0]				// (1, 2, 3) 
			tup[0][2]			// 3 
			tup[1][-2]			// 4

			- Tốc độ truy xuất của Tuple nhanh hơn so với List
