Lesson 12 -- Kiểu dữ liệu Dict -//

I> Khái niệm 
	- Dict(Dictionary) cũng là một container như LIST, TUPLE . Có điều khác biệt là những container 
	như List , Tuple  có các INDEX đê phân biệt các phần tử thì Dict dùng key để phân biệt 
	
	* Được giới hạn bởi cặp ngoặc nhọn{} 
	* Các phần tử được cách nhau bởi dấu , 
	* Phần tử có dạng key:value 
	* CÁC KEY BẮT BUỘC PHẢI LÀ MỘT HASHABLE OBJECT (int ,str , float , tuple )
	
II> Định nghĩa  
	* Mapping object cũng gần giống với dict object 
			- Một object là Mapping object là khi có đủ hai phương thức keys và __getitem__ 
			- Dict object cũng là một mapping object. Tuy nhiên, không phải mapping object nào cũng là dict object vì
				dict object không chỉ có hai phương thức keys và __getitem__ mà còn nhều phương thức khác 
			-> Tóm lại Mapping object là class abstract của Dict Object 	

				class Map_Class:
						def keys(self):
								return [1, 2, 3]
						def __getitem__(self, key):
								return key * 2	

	1. 	Khởi tạo 
		- Gán giá trị trực tiếp : 
								_dic = {'name' : 'bao' , 'age':10 , 10 : 10}
								_empty_dict = {}
	
		
		-	Sử dụng Dict Comprehension  // Điều kiện duyệt là mỗi giá trị được duyệt qua phải bao gồm một giá trị tương ưng với key và một giá trị tương ứng với value
								_dict = {key : value for key , value in [('name' , 'bao') , ('age',18)] } 
				
	
	
		- Sử dụng constructor Dict 
					
						- dict() 				// Khởi tạo một dict rỗng 
						- dict(mapping)			// Khởi tạo một dict từ một mapping object
						- dict(map_obj )		// Khởi tạo một dict từ map_obj
						- dict(iterable)		// khởi tạo bằng iterable (Iterable này đặc biệt hơn 
													các iterable để khởi tạo List hay Tuple , đó là các phần tử trong iterable
													phải có 2 value đó chính là cặp key-value , Có thể dùng List, Tuple , hoặc bất cứ container nào để chứa key-value (trừ 	mapping objetc ))
													// Nếu nhiều hoặc ít hơn 2 giá trị thì sẽ lỗi chương trình 
						
													iter_ = [('name', 'Kteam'), ('member', 69)]
													dic = dict(iter_)		// {'name': 'Kteam', 'member': 69}
													
													f = [('ab'), ('cd')]			// {'a': 'b', 'c': 'd'}
													
													
						- dict(**kwargs)		 //khởi tạo bằng keyword arguments ,
												// tức là sử dụng biến để khởi tạo , và tên biến sẽ được làm key dạng str của dict 
												// giá trị thực tế của biến đó sẽ k bị ảnh hưởng sau hàm khởi tạo dict 
												
												
												name="xxxx"
												age=100
												dic = dict(name='BAO' , age=18)		
												print(dic)							//{'name': 'BAO', 'age': 18} 
												print(name)                          // xxxx		giá trị không bị thay đổi
												print(age)                           // 100			giá trị k bị thay đổi 
												
						
						- dict.fromkeys(iterable,value)		// Khởi tạo một dict với key nằm trong một iterable, các value của các key đều là value 
															// Nếu k truyền value thì các key này có giá trị mặc định là none 
													
																iter_ = ('name' ,'age','phone')
																dic_none_val = dict.fromkeys(iter_)
																print(dic_none_val)			// {'name': None, 'age': None, 'phone': None}
																dic = dict.fromkeys(iter_,'GENERAL VALUE')
																print(dic)					// {'name': 'GENERAL VALUE', 'age': 'GENERAL VALUE', 'phone': 'GENERAL VALUE'}




						
III>  Thao tác 	// dic =  {'name': 'bao', 'age': 16 , 1 : 'One'}
	1. Indexing cũng k hẳn vì nó k có index -> Cách lấy value và Key
		- dic['name']				// bao 
		- dic['age']				// 16
		- dic[1]					//	One 
												
												
												
												
	2. Thay đổi nội dung # Vì là unhash object do đó ta có thể thay đổi nội dung giống như list 
		
		dic['name'] += 'DEP TRAI'		// {'name': 'bao DEP TRAI', 'age': 16}
		
												
	3. Thêm phần tử vào trong dict -> Thêm một key chưa tồn tại vào dict , nếu có tồn tại thì sẽ thay thế, chưa tồn tại thì thêm  
		
			dic['phone'] = '1 2 3 4 5 6 7 '	// {'name': 'bao', 'age': 16, 'phone': '1 2 3 4 5 6 7 '}

	
IV> Các phương thức 

///---- Các phương thức tiện ích  
	
		-	.copy()  		// sao chép một dict , trả về một dict mới 
		
		-	.clear()		// Loại bỏ tất cả các phần tử trong Dict 
	
///---- Các phương thức xử lý 
		
		-	.get(key[,default])	// trả về Value của Key truyền vào 
								// nếu Key không tồn tại thì trả về giá trị default 
								// Mặc định không truyền gì thì default = None 
								// print(dic2.get('ages','không tồn tại key đã truyền vào'))


		-	.items()			// trả về một giá trị thuộc lớp dict_items 
								// * Các giá trị của dict_items sẽ là một tuple với giá trị thứ nhất là Key , giá trị thứ 2 là Value  -> dict_items là một iterable |  <class 'dict_items'>
								// Giống như list có [] nhưng là một dict_items chứ k phải list 			
									
						
		- 	.keys()				// Trả về một giá trị thuộc lớp dict_keys	, là toàn bộ các key của dict 
								// dict_keys là một iterable 


		-	.values()			// Trả về một giá trị thuộc lớp dict_values	, là toàn bộ các value của dict 
								// dict_values là một iterable 


		-	.pop(key[,default])					//	Lấy ra và bỏ đi phần tử có Key và trả về value của key đó 					
												// Nếu không tồn tại thì báo lỗi Key Error nếu Không truyền default  -> luôn truyền default để bắt lỗi 



		-	.popitem()					// Lấy ra và bỏ đi một cặp keyvalue tương ứng bất kỳ(lấy thao giá trị hash của key từ lớn đến bé ) 
										// Nếu là một empty dict gọi hàm này sẽ báo lỗi 
										// Lấy ra cặp key-value cuối cùng đã thêm vào dict , tức là lấy ra từ cuối trở đi
										 // dict không thể chèn các giá trị vào giữa được cho nên nó sẽ cứ lấy từ cuối lấy đi 

	
	
	
	
		-	.setdefault(key,[default])		// Trả về Value của key trong dict 
											// Nếu key không có trong dict sẽ trả về default 		
											// Nếu key không tồn tại Một cặp key value mới sẽ được thêm vào dict bằng với key = key , value=default , default k truyền sẽ mặc định là None 
											
											
											
		-	.update[E,]**F)					// Cập nhật nội dung cho Dict 
		
		
											// F là một Dict được tạo bởi packing arguments
											for k in F: D[k] = F[k]
											
											d = {'a' : 1}
											print(d)			// 		{'a': 1}
											d.update(b=2,c=3)
											print(d)			// 		{'a': 1, 'b': 2, 'c': 3}
											
											
											// Nếu E được truyền vào đối tượng E có phương thức keys(), (Tức phải là Dict hay gì đó có keys() )thì sẽ cập nhật dict bằng cách 
											for k in E: D[k] = E[k]
											d = {'a' : 1}
											E = {'b':2,'c':3}
											d.update(E)
											print(d)				// {'a': 1, 'b': 2, 'c': 3}
											
											
											// Nếu E được truyền vào đối tượng E, đối tượng này có các giá trị là một container chứa 2 giá trị(cặp giá trị mới đc, nhiều ít hơn sẽ lỗi ) thì sẽ cập nhật dict bằng cách 
											for k, v in E: D[k] = v	
											
											d = {'a' : 1}
											E = {'b':2,'c':3}
											d.update(E)
											print(d)				// {'a': 1, 'b': 2, 'c': 3}	
											E_f = (['d',69], ['e',96])
											d.update(E_f)
											print(d)				// {'a': 1, 'b': 2, 'c': 3, 'd': 69, 'e': 96}
											
											
											
											
											
											
				-	<DictA> | <DictB>		// Toán tử | với 2 Dict 
											// Trả về một dict mới với các cặp key - value có mặt ở 1 trong 2 dict 
											// Nếu một key bất ký có trong cả 2 dict , thì giá trị được lấy sẽ là cặp key - value ở Dict_B 
											
											print({'1': 1, '2': 2} | {3: '3', 4: '4'})         // {'1': 1, '2': 2, 3: '3', 4: '4'}
											print({'1': 1, '2': 2} | {'1': 'x', '2': 'y'})     // {'1': 'x', '2': 'y'}
