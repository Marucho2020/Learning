// Toán hạng: có thể là một hằng số, biến số (X , Y)
// Toán tử: xác định cách thức làm việc giữa các toán hạng (+,-,*,/) 
	--> Một số biểu thức toán học của kiểu dữ liệu số trong Python 
	X + Y =  tổng 
	X - Y =  hiệu 
	X * Y =  tích 
	X / Y = thương 
	X // Y = Thương nguyên của X với Y  (Kết quả luôn luôn nhỏ hơn hoặc bằng X / Y ) 
	X % Y = Chia lấy dư
	X **Y = Lũy thừa mũ Y với cơ số x  (x^y)

// := 						// Assignment exprestion
ược gọi là toán tử gán biểu thức (walrus operator), được giới thiệu từ Python 3.8. Toán tử này cho phép bạn gán một giá trị cho biến ngay trong một biểu thức, 
giúp mã nguồn trở nên ngắn gọn và dễ đọc hơn trong các trường hợp nhất định.
 -> tức là cứ cho cái biểu thức mà trả về giá trị vào trong ngoặc , rồi ta có thể gán giá trị của nó cho một biến mà không cần phải viết riêng một dòng gán giá trị 

# Không dùng toán tử := 
value = len(input("Nhập chuỗi: "))  # Gán trước
if value > 5:
    print(f"Chuỗi dài hơn 5 ký tự: {value}")

# Dùng toán tử :=
if (value := len(input("Nhập chuỗi: "))) > 5:
    print(f"Chuỗi dài hơn 5 ký tự: {value}")
