3. match-case 
	Cấu trúc mới trong Python3.10 , Thay vì kiểm tra điều kiện, nó kiểm tra các trường hợp có thể xảy ra đối với một giá trị 
	
	giống với switch- case 
	
	nếu vào một giá trị thì sẽ mặc định break ra khỏi luôn 
	
	match <subject>:

    case <pattern_1>:

        <action_1>

    case <pattern_2>:

        <action_2>

    case <pattern_3>:

        <action_3>

    case _:							// Nếu k có cái nào ở trên vào thì sẽ vào đây , _ 

        <action_wildcard>
	
	
	
// e.g  Không vào case nào thì sẽ vào case default 
t = 5
match t :
	case 1 : 
		print("t == 1")
	case 2 : 
		print("t == 2")
	case 3 :
		print("t == 3")
	case 9 :
		print("t == 5")
	case _: 
		print("t not match")
	
	
	
	t not match
	
	
	
// e.g    trùng Case 
t = 1
match t:
    case 1: # case (1)
        print("t = 1")
    case 1: # case (2)
        print("t là 1")
		
	t = 1		// Nếu các case giống nhau thì sẽ vào cái case được phù hợp đầu tiên rồi break 	


	
	
// e.g    Sử dụng toán tử or (|) , if với case để mở rộng pattern 
	
t = 10
match t:
    case 1|2|3|4: 
        print("t = 1")
    case 10 if t >= 10: 
        print("t là 1")
	
	t là 1
	

4./ Block  trong Python 
	- Không sử dụng {} như các ngôn ngữ khác mà sử dụng thụt đầu dòng  
	- Câu lệnh mở block kết thúc bằng dấu hai chấm (:) buộc phải thụt lùi về trong và có tối thiểu một câu lệnh để không bỏ trống block 
	
	- Những dòng code cùng lề thì cùng là một block 
	- Một block có thể có nhiều block khác 
	- khi căn lề block KHÔNG sủ dụng LẪN tab và space 
	- Nên sử dụng 4 space để căn lề một block
