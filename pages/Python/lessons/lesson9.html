- Sử dụng List Comprehension 
		// Cách này là một cách ngắn gọn và hiệu quả để tạo ra danh sách mới từ danh sách có sẵn hoặc từ bất kỳ iterable nào.
			Nó giúp ta viết các vòng lặp và điều kiện ngay bên trong danh sách một cách dễ dàng và gọn gàng hơn so với cách viết thông thường 
		  
	Cú pháp 
		[expression for item in iterable if condition ]
			 + expression                 : là biểu thức được áp dụng lên từng phần tử item của iterable 
			 + for item in iterable       : là vòng lặp chạy qua từng phần tử của iterable 
			 + if condition               : là điều kiện để LỌC các phần tử thỏa mãn 
			 
			 squares = [x**2 for x in range(1 ,  11) if x%2==0]  // vòng lặp để tạo danh sách chứa các số bình phương chẵn từ 1 đến 10 
			  print(squares)

2. Một số toán tử trong List 
			
	# Toán tử  +     					// Nối 2 list 
		print(list("HELLO") + list("WORLD"))  //['H', 'E', 'L', 'L', 'O', 'W', 'O', 'R', 'L', 'D']
	
	
	# Toán tử * 						// Nhân với số nguyên để tăng số lần của phần tử 
		print(list("HELLO") *2)			// ['H', 'E', 'L', 'L', 'O', 'H', 'E', 'L', 'L', 'O']
	
	
	# Toán tử in  						// Kiểm tra phần tử có tồn tại bên trong chuỗi hay không , trả về True or False 
		print('1' in [1, 2, 3])	// False 
		print(1 in [1, 2, 3])	// True 
		
		
		
		
	**Các toán tử so sánh	
	// Khi so sánh 2 list , chương trình sẽ lần lượt so sánh các phần tử có cùng vị trí trong 2 list , 
	// Nếu xuất hiện 2 giá trị khác nhau thì kết quả của phép so sánh sẽ là kết quả khi so sánh giá trị 2 list đó 
	// Khi so sánh đến hết một trong 2 list nhưng vẫn k có giá trị khác biẹt thì chương trình sẽ so sánh độ dài của 2 list và trả về giá trị tương ứng 
	// Khi so sánh  <> chuỗi thì sẽ so sánh giá trị trong bảng ASCII của nó với nhau 
	
	Toán tử  ==     // so sánh xem 2 list có giống nhau hay ko 
	Toán tử  >  	
	Toán tử  <  
	
	print([1, 2, 3] == [1, 2, 3])  // True 
	print([1, 2, 3] == [1, '2'])	// False 
	
	print([1, 2, 3] > [1, 2])  	// True 
	print([1, 2, 3] > [1, '2'])  	// SO SÁNH SỐ VỚI CHUỖI SẼ LỖI -> HÀM NÀY LỖI CHƯƠNG TRÌNH 
	print(['b', 'c', 'd'] < ['x', 'y', 'z'])	// True 
	print(['a'] > ['b'])						// False 
	print(['a'] > ['B'])						// True 
	
		
	**Indexing và cắt chuỗi   lst = [1, 2, 'a', 'b', [3, 4]]
	dấu :: trong Python được gọi là SLICE NOTATION (Ký hiệu cắt lát ) , CHo phép lấy ra các phần tử từ một danh sách hoặc chuỗi con 
			Bằng cách chỉ định bước nhảy , điểu bắt đầu và điểm kết thúc 
			
	lst[start:stop:step]		
	
		
		print(lst[0])			//  	1			                      //  lấy ra phần tử index  = 0 
		print(lst[-1])			//  	[3, 4]                            //  Lấy ra phần tử index  -1 
		print(lst[1:-1])		//  	[2, 'a', 'b']                     //  Lấy ra các phần tử từ index = 1 đến index -1 	  (index = -1 lúc này tương ứng với index = length - 2 )
		print(lst[::-1])		//  	[[3, 4], 'b', 'a', 2, 1]          //  Đảo ngược chuỗi :   lấy ra các phần tử từ -1 đến 0 theo vị trí từ phải sang trái và theo bước là -1 
		print(lst[1::])			//  	[2, 'a', 'b', [3, 4]]             // Lấy từ phần tử index bằng 1 và end và bước là mặc định  , end mặc định sẽ là đết hết , bước mặc định là 1 
		print(lst[:-1])			//  	[1, 2, 'a', 'b']                  // Lấy từ phần tử start = 0  đến phần tử end là -1 , cắt bắt đầu từ 0 và kết thúc tại vị trí > -1 
		print(lst[:1])			//  	[1]                               // Cắt bắt đầu từ  0  và kết thúc tại vị trí Index < 1 
		print(lst[::-2])		// 		[[3, 4], 'a', 1]				 // Cắt ngược và mỗi lần lùi 2 bước

5. Các vấn đề cần lưu ý 
 
	Cũng giống như Java , List trong Python là dạng biến tham chiếu -> Gán =  cho list khác cũng tức là đang gán vùng tham chiếu cho nó 
	// VÀ KHI THAY ĐỔI GIÁ TRỊ TẠI MỘT LIST THÌ LIST CÒN LẠI SẼ BỊ THAY ĐỔI THEO , nên khi sao chép ta phải dùng hàm copy 
	
	
	- Toán tử is 
	
		Cú pháp: A is B  // kiểm tra xem 2 biến có cùng tham chiếu đến một vùng nhớ hay không , nếu đúng trả về True , sai trả về False
		// ĐỪNG bao giờ sử dụng toán tử is đối với 2 biến thuộc kiểu số hoặc chuỗi , vì nó không mang lại ý nghĩa nào cả 
		// số và str là kiểu dữ liệu nguyên thủy nên chắc chắn sẽ là False 
		// Các phép so sánh một biến với giá trị None luôn được thực hiện bằng toán tử is 
		e.g 
		
		lst = [[1, 2, 3], [4, 5, 6]]
		lst2 = lst
		print(lst2 is lst)  // True
		
		# -- Các cách copy 
		# Cách 1  : Khởi tạo list mới bằng Constructor 
		lst = [1 , 2 , 3]
		lst_copy_1 = list(lst)
		print(lst_copy_1 is lst)

		# Cách 2  : Sử dụng phương thức duyệt mảng để lấy ra mảng mới 
		lst_copy_2 = lst[:] 
		lst_copy_2 is lst   //False
		
		# Cách 3: dùng phương thức copy()
		lst_copy_3 = lst.copy() 
		lst_copy_3 is lst //False 
		

		Lưu ý: nó chỉ sao chép các phần tử của List. 
		Không hề sao chép các phần tử con của các phần tử nằm trong List. 
		Do đó, nếu bạn thay đổi các phần tử trong List thì không sao, 
		tuy nhiên nếu thay đổi phần tử con của các phần tử trong List, thì vấn đề lại xuất hiện.

		-  .count(sub,[,start[,end]])		// trả về một số nguyên là số lượng phần tử sub tồn tại  trong chuỗi

		-  .clear()							// xóa mọi phần tử trong list 
		
		
		-  .append(x)						// Thêm một phần tử x mới vào cuối list 	
											lst.append(list('xy'))

											lst.extend(list('xy'))
											print(lst)									//  [1, 2, 3, 'x', 'y']
		
		
		-   .insert(i,x)				// Chèn phần tử x vào vị trí i trong list 
										// Nếu I không nằm giữa , lớn hơn max index của list thì sẽ giống như append -> // thêm vào cuối list 
										lst.insert(0,list('xy'))

										lst.insert(-1,list('xy'))								// 	print(lst)
		
		- 	.pop([i])					// Lấy ra và trả về phần tử thứ i trong list 
										// Nếu truyền vào rỗng thì mặc định sẽ lấy và bỏ đi phần tử cuối cùng 
		
		
		- 	.remove(x)					// Xóa phần tử đầu tiên từ trái sang phải có GIÁ TRỊ  là x 
										// Nếu không có phần tử phù hợp được xóa thì sẽ trả về lỗi 
		
		
		-	.reverse()					// Đảo ngược chuỗi 
		
		
		-	.sort(key=None,reverse=False)	// Sắp xếp các phần tử từ bé đến lớn bằng cách so sánh trực tiếp.
											// Mặc định khi k truyền reverse sẽ là False = KHÔNG ĐẢO NGƯỢC 
											// Nếu truyền là TRUE thì sẽ là sắp xếp từ Lớn đến bé 
											// Nếu k truyền vào Key , hoặc Key None thì sẽ sắp xếp mặc định theo giá trị 
											
								lst = ["aaaaa",'bbbb','ccc','dd']
								lst.sort(key=len,reverse=False)				// Key =  len -> Sắp xếp theo len 
								print(lst)								// ['dd', 'ccc', 'bbbb', 'aaaaa']
											
								OR 
								lst = ["aaaaa",'bbbb','ccc','dd']
								lst.sort(key=str,reverse=False)			// Key = str  -> Sắp xếp bằng việc so sánh các chuỗi ASCII
								print(lst)								// ['aaaaa', 'bbbb', 'ccc', 'dd']
