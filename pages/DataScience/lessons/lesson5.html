# 1. Python Trong Data Science (Python)

	Định nghĩa chính: Python là ngôn ngữ lập trình được Data Scientist sử dụng rộng rãi nhờ các thư viện toán học tích hợp, giúp dễ dàng tính toán và phân tích dữ liệu. Tutorial sẽ cung cấp ví dụ thực hành với Python.

	## Giải thích chi tiết và chuyên sâu
		Tại sao chọn Python?: Python có cú pháp đơn giản, dễ học (so với R hoặc Java), và cộng đồng lớn, hỗ trợ nhiều thư viện mạnh mẽ. Nó phù hợp cho mọi bước trong quy trình Data Scientist (bài thứ hai): từ thu thập, làm sạch, phân tích đến trình bày kết quả.

		Thư viện toán học: Python có các hàm built-in như sum(), len() để tính trung bình, nhưng sức mạnh nằm ở các thư viện như NumPy (cho phép tính toán ma trận nhanh) và SciPy (cho thống kê nâng cao). Ví dụ: Trong bài đầu tiên, chúng ta dùng scipy.stats.linregress để tính hồi quy tuyến tính.

		Ví dụ minh họa cụ thể: Kết nối với bài đầu tiên (hồi quy tuyến tính với Average_Pulse và Calorie_Burnage), mã Python:
		
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
full_health_data = pd.read_csv("data.csv", header=0, sep=",")
x = full_health_data["Average_Pulse"]
y = full_health_data["Calorie_Burnage"]
slope, intercept, r, p, std_err = stats.linregress(x, y)

		Đây là ví dụ điển hình của Python trong Data Science: Pandas đọc dữ liệu, SciPy phân tích, Matplotlib visualize (biểu đồ scatter và đường hồi quy).

		Ứng dụng thực tế: Các công ty như Google dùng Python để phân tích dữ liệu người dùng (ví dụ: dự đoán hành vi tìm kiếm), vì tốc độ và tính linh hoạt của Python.



# 2. Các Thư Viện Python (Python Libraries)

	Định nghĩa chính: Python có các thư viện với bộ sưu tập hàm toán học và công cụ phân tích. Bài giới thiệu bốn thư viện chính:
		- Pandas: Xử lý dữ liệu có cấu trúc (structured data) – đọc CSV, tạo DataFrame, chuẩn bị dữ liệu.
		- NumPy: Thư viện toán học với mảng N-chiều, đại số tuyến tính, biến đổi Fourier, v.v.
		- Matplotlib: Visualize dữ liệu (biểu đồ).
		- SciPy: Chứa các module đại số tuyến tính và thống kê.

	## Giải thích chi tiết và chuyên sâu: 
		Pandas:

	Chức năng: Dùng cho dữ liệu dạng bảng (như database table trong bài trước). DataFrame (cấu trúc giống Excel) là công cụ chính, hỗ trợ đọc CSV, làm sạch dữ liệu, lọc, nhóm.

	Ví dụ cụ thể: Dựa trên bảng sức khỏe (Duration, Average_Pulse, Calorie_Burnage, v.v.):

import pandas as pd
# Tạo DataFrame từ dữ liệu bài trước
data = {
    'Duration': [30, 30, 45, 45, 45, 60, 60, 60, 75, 75],
    'Average_Pulse': [80, 85, 90, 95, 100, 105, 110, 115, 120, 125],
    'Max_Pulse': [120, 120, 130, 130, 140, 140, 145, 145, 150, 150],
    'Calorie_Burnage': [240, 250, 260, 270, 280, 290, 300, 310, 320, 330],
    'Hours_Work': [10, 10, 8, 8, 0, 7, 7, 8, 0, 8],
    'Hours_Sleep': [7, 7, 7, 7, 7, 8, 8, 8, 8, 8]
}
df = pd.DataFrame(data)
print(df.describe())  # Mô tả thống kê

## NumPy:
	Chức năng: Thư viện toán học mạnh mẽ, tối ưu cho mảng (array) và tính toán nhanh (vectorized operations). Hỗ trợ đại số tuyến tính (linear algebra), biến đổi Fourier (xử lý tín hiệu), và random sampling.

	Ví dụ cụ thể: Tính trung bình và độ lệch chuẩn của Average_Pulse:

import numpy as np
pulse = np.array([80, 85, 90, 95, 100, 105, 110, 115, 120, 125])
mean = np.mean(pulse)  # 102.5
std = np.std(pulse)    # 15.14
print(f"Mean: {mean}, Std: {std}")

	Phân tích: NumPy nhanh hơn list Python vì dùng C backend. Trong big data, NumPy xử lý hàng triệu giá trị hiệu quả.


	Ứng dụng thực tế: NumPy dùng trong machine learning (Scikit-learn dựa trên NumPy) để tính toán ma trận, như trong mô hình hồi quy.


# Matplotlib: 
	Chức năng: Visualize dữ liệu bằng biểu đồ (scatter, line, histogram, v.v.). Dùng để trình bày insights (bước cuối quy trình Data Scientist).
	
	Ví dụ cụ thể: Vẽ biểu đồ từ bài đầu:
	
import matplotlib.pyplot as plt
plt.scatter(df['Average_Pulse'], df['Calorie_Burnage'])
plt.xlabel('Average_Pulse')
plt.ylabel('Calorie_Burnage')
plt.show()


	Phân tích: Biểu đồ scatter cho thấy Average_Pulse và Calorie_Burnage có mối quan hệ tuyến tính, như đã dự đoán trong bài đầu.

	Ứng dụng thực tế: Matplotlib dùng để báo cáo cho stakeholders (ví dụ: biểu đồ doanh thu hàng tháng cho CEO).
	
	
	
# SciPy
	Chức năng: Chứa các module thống kê và đại số tuyến tính, như hồi quy tuyến tính (stats.linregress) trong bài đầu.
	
	Ví dụ cụ thể: Tính tương quan Pearson và p-value:
	
from scipy import stats
r, p = stats.pearsonr(df['Average_Pulse'], df['Calorie_Burnage'])
print(f"Correlation: {r}, P-value: {p}")	
	
		Output: Correlation ≈ 1.0, P-value rất nhỏ (< 0.05), chứng tỏ mối quan hệ mạnh và có ý nghĩa thống kê.
	
		Ứng dụng thực tế: SciPy dùng để kiểm định giả thuyết (hypothesis testing) hoặc tối ưu hóa mô hình (optimization).
