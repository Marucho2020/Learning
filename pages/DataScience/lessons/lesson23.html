	→ P-value chính là câu trả lời!

# PHẦN 2: 4 CỘT TRONG BẢNG HỆ SỐ (COEFFICIENTS)

Cột,Tên,Ý nghĩa
std err,Standard Error,Độ không chắc chắn của hệ số
t,t-value,Hệ số chia cho std err
`P>,t,`
[0.025 0.975],95% Confidence Interval,Khoảng hệ số có thể nằm vào với 95% xác suất


	Hôm nay ta tập trung vào P>|t| – P-value




# PHẦN 3: P-VALUE LÀ GÌ? (GIẢI THÍCH DỄ HIỂU NHẤT)
	Ví dụ đời thường:

	Bạn nói: "Tập thể dục 30 phút giúp giảm 1kg/tuần!"
	Bạn bè nghi ngờ: "Làm sao chắc? Có khi ngẫu nhiên thôi!"

→ Bạn làm thí nghiệm với 100 người → kết quả ủng hộ bạn.
→ Bạn tính P-value = 0.01


P-value = 0.01 nghĩa là:
	"Chỉ có 1% khả năng kết quả này là do ngẫu nhiên. 99% là do tập thể dục thực sự hiệu quả!"



Câu hỏi,P-value trả lời
Average_Pulse có ảnh hưởng đến Calorie_Burnage không?,→ Xem P-value của hệ số Average_Pulse


# PHẦN 4: GIẢ THUYẾT (HYPOTHESIS TESTING) – TOÀN BỘ QUY TRÌNH

Bước 1: Đặt giả thuyết

Giả thuyết,Ý nghĩa
H₀ (Null Hypothesis),Không có mối quan hệ → Hệ số = 0
Hₐ (Alternative Hypothesis),Có mối quan hệ → Hệ số ≠ 0

H₀: β_Average_Pulse = 0
Hₐ: β_Average_Pulse ≠ 0



# Bước 2: Tính P-value
	→ Dùng công thức t-statistic:

	$t = \frac{\text{coef}}{\text{std err}}$
	→ Tra bảng t hoặc dùng phần mềm → ra P-value


# Bước 3: Ra quyết định

P-value,Kết luận
< 0.05,Bác bỏ H₀ → Có mối quan hệ ý nghĩa
> 0.05,Không đủ bằng chứng bác bỏ H₀ → Không kết luận được

	0.05 = ngưỡng phổ biến (5% rủi ro sai)



# PHẦN 7: INTERCEPT – CÓ NÊN XEM P-VALUE KHÔNG?

	Intercept là điểm neo của đường thẳng
	Dù P-value cao, vẫn cần giữ để mô hình chính xác
	Chỉ quan tâm P-value của biến giải thích (X)



# TÓM TẮT NHỚ NHANH (CHEAT SHEET)

Khái niệm,Ý nghĩa,Ví dụ
P-value < 0.05,Có mối quan hệ ý nghĩa,Bác bỏ H₀
P-value > 0.05,Không đủ bằng chứng,Không kết luận
H₀,Hệ số = 0 (không ảnh hưởng),β = 0
Hₐ,Hệ số ≠ 0 (có ảnh hưởng),β ≠ 0
0.05,Ngưỡng chấp nhận rủi ro 5%,Tiêu chuẩn
