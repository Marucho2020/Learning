Lesson 2 -- Cú pháp và các tính năng quan trọng của Kotlin -//

	I : > Biến  và kiểu dữ liệu 
		
		Kotlin có hai loại biến : 
			val  (immutable )	: không thể thay đổi sau khi khởi tạo ->> giống final trong Java  
			var  (mutable)		: Có thể thay đổi sau khi khởi tạo 
			
				#e.g 1 : Ví dụ khởi tạo biến 
					val name : String = "John"				// Giá trị này sẽ không thể thay đổi về sau 
					var age  : Int = 25 					// Biến này có thể gán lại giá trị mới 
					
		
	II : > Hàm và biểu thức lambda	
	
		#Kotlin sử dụng từ khóa fun để khai báo hàm và gọn gàng khá giống với python 
			
			# e.g 2 : Khai báo hàm   -> giống với python về cú pháp tên hàm , param  và KDL trả về , và giống với Java ở chỗ là sử dụng cặp ngoặc {} để khai báo nội dung hàm  
				fun sum (a : Int ,  b : Int) : Int {
					return a + b
				}
		

		# Biểu thức lambda
			
			val multiply = {a : Int , b : Int -> a * b}			// giống với lambda trong Java nhưng kiểu dữ liệu lại giống Python là đặt sau dấu : 
			
			
	III : > Null Safety (An toàn với null )
		
		Kotlin yêu cầu khai báo rõ ràng các biến có thể null hay không bằng dấu ? sau kiểu dữ liệu , nếu có thì có nghĩa là giá trị này có thể null , điều này giúp người dùng xác định rõ ràng hơn trong khi lập trình để tránh những trường hợp xảy ra null nên mới gặp lỗi 
		
			# e.g3 khai báo biến có thể được sử dụng giá trị null 
				var name : String? = null 				// sử dụng dấu ? sau String thành String? khai báo chỗ này biến name có thể nhận cả giá trị null
	
	
	
	IV : > Data Classes (Lớp dữ liệu)
		Kotlin hỗ trợ data classes, là các lớp được thiết kế để lưu trữ dữ liệu với cú pháp ngắn gọn 
			
			#e.g 4 Ví dụ sử dụng data classes để tạo lớp User nhanh chóng ngắn gọn 
				data class User(val name:String, val age : Int)
		
	
	V : > Extension Functions(Hàm mở rộng )
		Kotlin cho phép thêm các hàm mới vào các lớp hiện có mà không cần kế thừa hoặc sửa đổi lớp đó 
		
			#e.g5 Sử dụng Extension Function để gán thêm hàm cho một lớp mà không cần phải trực tiếp sửa class file của lớp đó 
			fun String.addHello(): String { 					// thêm vào lớp String hàm addHello()
				return "Hello $this"
			}
			
	VI : > Coroutines (Đồng bộ không đồng bộ )
		Coroutines là một tính năng nổi bật của Kotlin cho phép thực hiện các tác vụ bất đồng bộ mà không cần dùng đến Thread phức tạp. Đây là tính năng mạnh mẽ giúp Kotlin nổi bật trong phát triển ứng dụng Android
