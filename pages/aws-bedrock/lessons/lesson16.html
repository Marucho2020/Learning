# 10. Trade-off

| Thiết kế                        | Ưu điểm                                                                             | Nhược điểm                                                                                                |
| ------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Gọi API trực tiếp tới Anthropic | Ít lớp trung gian, có thể dùng ngay các tính năng mới nhất của nhà cung cấp         | Khó đổi model, IAM tích hợp kém, phải tự xây logging, guardrails, governance                              |
| Qua Bedrock                     | Quản trị tập trung, IAM, Guardrails, Knowledge Bases, Agents, quan sát hệ thống tốt | Có thêm một lớp trừu tượng, đôi khi một số tính năng mới của model xuất hiện trên API gốc sớm hơn Bedrock |



Điểm cần nhớ: Trong môi trường AWS Enterprise và trong kỳ thi AIP-C01, Bedrock thường là lựa chọn mặc định khi yêu cầu là "giảm công sức vận hành", "quản trị tập trung", "đa mô hình", "bảo mật" hoặc "governance".



# 11. Từ khóa thường xuất hiện trong đề thi

| Keyword          | Ý nghĩa cần liên tưởng                              |
| ---------------- | --------------------------------------------------- |
| Bedrock Runtime  | API dùng để suy luận (inference)                    |
| Foundation Model | Mô hình nền (Claude, Nova, Llama, Titan...)         |
| InvokeModel      | Gửi request tới model                               |
| Converse API     | API hội thoại thống nhất cho nhiều model            |
| Model Access     | Quyền sử dụng model                                 |
| Inference        | Quá trình sinh kết quả từ model                     |
| Abstraction      | Lớp trừu tượng giúp tách ứng dụng khỏi model cụ thể |
| Managed Service  | AWS quản lý hạ tầng và vận hành                     |
| Multi-model      | Có thể chuyển đổi giữa nhiều Foundation Model       |



# 13. Các bẫy (Trap) trong kỳ thi

| Bẫy                                   | Sự thật                                                                                                                          |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Bedrock là Foundation Model           | ❌ Sai. Bedrock là nền tảng quản lý và truy cập nhiều Foundation Model.                                                           |
| Bedrock tự huấn luyện model           | ❌ Sai. Bedrock không train model.                                                                                                |
| Claude chạy bên trong Bedrock         | ❌ Không chính xác. Bedrock cung cấp quyền truy cập và hạ tầng suy luận được AWS quản lý; model vẫn thuộc nhà cung cấp tương ứng. |
| Muốn dùng Bedrock bắt buộc dùng Titan | ❌ Sai. Có thể dùng Claude, Nova, Llama, Mistral và nhiều model khác.                                                             |
| Bedrock luôn là lựa chọn đúng         | ❌ Sai. Nếu yêu cầu là dùng tính năng mới nhất hoặc API đặc thù của nhà cung cấp, API trực tiếp có thể phù hợp hơn.               |
