# 1. Tổng quan về Class Components
	Tóm tắt: Trước React 16.8, Class Components là cách duy nhất để quản lý trạng thái (state) và vòng đời (lifecycle) trong React. Hiện nay, Function Components với Hooks đã thay thế gần như hoàn toàn, nhưng Class Components vẫn được hỗ trợ và hữu ích khi làm việc với mã cũ.

	Class Components là gì?: Là các component được định nghĩa bằng cú pháp class của ES6, kế thừa từ React.Component. Chúng sử dụng phương thức render() để trả về JSX và có thể quản lý state, props, và các lifecycle methods.


	## So sánh với Function Components: 
		Class Components: Cú pháp phức tạp hơn, sử dụng this, cần constructor và super() để khởi tạo. Hỗ trợ state và lifecycle methods một cách tự nhiên.
		
		Function Components: Ngắn gọn, dễ đọc, kết hợp Hooks để xử lý state và lifecycle. Được khuyến nghị từ React 16.8.


	## Tại sao cần học Class Components?:
	
		- Nhiều dự án cũ vẫn sử dụng Class Components.
		- Hiểu Class Components giúp bạn dễ dàng chuyển đổi sang Function Components hoặc bảo trì mã legacy.
		- Một số khái niệm (như lifecycle) vẫn áp dụng khi học Hooks.	
	
	
	
# 2. Tạo Class Component 
	Tóm tắt: Class Component phải kế thừa React.Component, có phương thức render() trả về JSX, và tên component phải bắt đầu bằng chữ in hoa.
	
	## Cú pháp cơ bản 
		
class Car extends React.Component {
  render() {
    return <h2>Hi, I am a Car!</h2>;
  }
}

	- extends React.Component: Kế thừa các tính năng của React, như state và lifecycle methods.
	- render(): Phương thức bắt buộc, trả về JSX để hiển thị giao diện.
	- Car: Tên component, bắt đầu bằng chữ in hoa (quy tắc React).	


	## Sử dụng:

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car />);

Gọi component như thẻ HTML: <Car />.
Kết quả: <h2>Hi, I am a Car!</h2> được hiển thị.


	## Sâu sắc hơn:
	
	Quy tắc đặt tên: Tên in hoa giúp React phân biệt component (như <Car />) với thẻ HTML (như <div>).
	
	JSX: Nội dung trong render() phải tuân theo quy tắc JSX (một phần tử cấp cao nhất, đóng thẻ đúng cách).
	
	
# 	3. Constructor và State
	Tóm tắt: Constructor khởi tạo state và props. State là một object lưu trữ dữ liệu của component, khi thay đổi sẽ kích hoạt re-render.	
	
	## Constructor 
class Car extends React.Component {
  constructor() {
    super();
    this.state = { color: "red" };
  }
  render() {
    return <h2>I am a {this.state.color} Car!</h2>;
  }
}	
	
	
	- constructor(): Được gọi khi component khởi tạo.
	- super(): Gọi constructor của React.Component, đảm bảo component kế thừa các tính năng của lớp cha.
	- this.state: Khởi tạo object state với thuộc tính color.
	- this.state.color: Truy cập state trong render() để hiển thị động.
	
	
	
	## Sử dụng state 
	
	State là nơi lưu trữ dữ liệu nội bộ của component (ví dụ: màu sắc, trạng thái giao diện).
	Khi state thay đổi (qua this.setState()), component sẽ tự động re-render.
	
class Car extends React.Component {
  constructor() {
    super();
    this.state = { color: "red" };
  }
  render() {
    return <h2>I am a {this.state.color} Car!</h2>;
  }
}

	## State vs Props:
		State: Dữ liệu nội bộ, có thể thay đổi bởi component (qua this.setState()).
		Props: Dữ liệu truyền từ bên ngoài, chỉ đọc (read-only).

	Không sửa state trực tiếp: Luôn dùng this.setState() để cập nhật state, đảm bảo React nhận biết thay đổi và re-render.

# 4. Props trong Class Components
	Tóm tắt: Props là các thuộc tính truyền vào component từ bên ngoài, truy cập qua this.props.

	## 	Ví dụ 

class Car extends React.Component {
  render() {
    return <h2>I am a {this.props.color} Car!</h2>;
  }
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car color="red" />);
	
	
	<Car color="red" />: Truyền prop color với giá trị "red".
	this.props.color: Truy cập prop trong render().
	Kết quả: <h2>I am a red Car!</h2>.	
	
	
	
	## Props trong constructor:
		Nếu component có constructor, props phải được truyền vào và gửi tới super():
		
class Car extends React.Component {
  constructor(props) {
    super(props);
  }
  render() {
    return <h2>I am a {this.props.model}!</h2>;
  }
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car model="Mustang" />);	
	
	constructor(props) và super(props): Đảm bảo props có thể truy cập qua this.props.
	
	Props là cách để component nhận dữ liệu động, giúp tái sử dụng component với các giá trị khác nhau.
	Props có thể là bất kỳ kiểu dữ liệu: chuỗi, số, object, hàm, hoặc thậm chí component khác.
	
	
	
	
# 	5. Components lồng Components 
	Tóm tắt: Class Components có thể được lồng trong nhau để tạo giao diện phức tạp.
	
	## Ví dụ:
	
class Car extends React.Component {
  render() {
    return <h2>I am a Car!</h2>;
  }
}

class Garage extends React.Component {
  render() {
    return (
      <div>
        <h1>Who lives in my Garage?</h1>
        <Car />
      </div>
    );
  }
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Garage />);	
	
	Garage là component cha, chứa component con Car.
	
<div>
  <h1>Who lives in my Garage?</h1>
  <h2>I am a Car!</h2>
</div>	
	
	Lồng component giúp chia nhỏ giao diện thành các phần độc lập, dễ bảo trì.
	Component con có thể nhận props từ component cha để hiển thị dữ liệu động.
	
	
# 6. Components trong File riêng	
	Tóm tắt: Đặt Class Components trong các file .js riêng để tái sử dụng và tổ chức mã tốt hơn.
	
	Giải thích chi tiết:
	
	## Tạo file Car.js 
import React from 'react';

class Car extends React.Component {
  render() {
    return <h2>Hi, I am a Car!</h2>;
  }
}

export default Car; 	
	
	##  Sử dụng trong index.js
	
import React from 'react';
import ReactDOM from 'react-dom/client';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car />);	
	
	
	
# 7. State và Lifecycle Methods

	Tóm tắt: Class Components có state để lưu trữ dữ liệu nội bộ và các lifecycle methods để quản lý vòng đời (mounting, updating, unmounting).
	
	
	## 7.1. State
		Khởi tạo state:
		
class Car extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      brand: "Ford",
      model: "Mustang",
      color: "red",
      year: 1964
    };
  }
  render() {
    return (
      <div>
        <h1>My {this.state.brand}</h1>
        <p>It is a {this.state.color} {this.state.model} from {this.state.year}.</p>
      </div>
    );
  }
}	
	
	this.state: Khởi tạo trong constructor với các thuộc tính như brand, model.
	Kết quả: Hiển thị thông tin xe dựa trên state.
	
	
	## Cập nhật state 
		Sử dụng this.setState() để thay đổi state và kích hoạt re-render:
	
class Car extends React.Component {
  constructor(props) {
    super(props);
    this.state = { color: "red" };
  }
  changeColor = () => {
    this.setState({ color: "blue" });
  }
  render() {
    return (
      <div>
        <h1>My Car is {this.state.color}</h1>
        <button onClick={this.changeColor}>Change color</button>
      </div>
    );
  }
}	
	
	this.setState({ color: "blue" }): Cập nhật color, khiến component re-render với giá trị mới.
	
	
# 7.2. Lifecycle Methods	
	Class Components có các phương thức đặc biệt để xử lý các giai đoạn trong vòng đời của component: Mounting, Updating, và Unmounting.
	
	## Mounting (Khi component được tạo và thêm vào DOM) 
	
		- constructor(): Khởi tạo state và props.
		- componentDidMount(): Chạy sau khi component được render lần đầu. Thường dùng để gọi API hoặc thiết lập timer: 
	
class Header extends React.Component {
  constructor(props) {
    super(props);
    this.state = { favoritecolor: "red" };
  }
  componentDidMount() {
    setTimeout(() => {
      this.setState({ favoritecolor: "yellow" });
    }, 1000);
  }
  render() {
    return <h1>My Favorite Color is {this.state.favoritecolor}</h1>;
  }
}	
	
	## Updating (Khi state hoặc props thay đổi):
		shouldComponentUpdate(): Quyết định có re-render hay không. Mặc định trả về true:
	
class Header extends React.Component {
  constructor(props) {
    super(props);
    this.state = { favoritecolor: "red" };
  }
  shouldComponentUpdate() {
    return true; // Cho phép re-render
  }
  changeColor = () => {
    this.setState({ favoritecolor: "blue" });
  }
  render() {
    return (
      <div>
        <h1>My Favorite Color is {this.state.favoritecolor}</h1>
        <button onClick={this.changeColor}>Change color</button>
      </div>
    );
  }
}	
	
	
	## getSnapshotBeforeUpdate(prevProps, prevState): Lưu lại giá trị trước khi update. Cần đi kèm componentDidUpdate:

class Header extends React.Component {
  constructor(props) {
    super(props);
    this.state = { favoritecolor: "red" };
  }
  componentDidMount() {
    setTimeout(() => {
      this.setState({ favoritecolor: "yellow" });
    }, 1000);
  }
  getSnapshotBeforeUpdate(prevProps, prevState) {
    document.getElementById("div1").innerHTML =
      "Before the update, the favorite was " + prevState.favoritecolor;
    return null;
  }
  componentDidUpdate() {
    document.getElementById("div2").innerHTML =
      "The updated favorite is " + this.state.favoritecolor;
  }
  render() {
    return (
      <div>
        <h1>My Favorite Color is {this.state.favoritecolor}</h1>
        <div id="div1"></div>
        <div id="div2"></div>
      </div>
    );
  }
}


	## Unmounting (Khi component bị xóa khỏi DOM)
		componentWillUnmount(): Chạy trước khi component bị xóa, thường dùng để dọn dẹp (như clear timer):
		
class Container extends React.Component {
  constructor(props) {
    super(props);
    this.state = { show: true };
  }
  delHeader = () => {
    this.setState({ show: false });
  }
  render() {
    let myheader;
    if (this.state.show) {
      myheader = <Child />;
    }
    return (
      <div>
        {myheader}
        <button onClick={this.delHeader}>Delete Header</button>
      </div>
    );
  }
}

class Child extends React.Component {
  componentWillUnmount() {
    alert("The component named Header is about to be unmounted.");
  }
  render() {
    return <h1>Hello World!</h1>;
  }
}



# Sâu sắc hơn:

State: Chỉ nên dùng cho dữ liệu thay đổi và ảnh hưởng đến giao diện. Dùng this.setState() để đảm bảo re-render.
Lifecycle Methods: Giúp kiểm soát hành vi của component ở các giai đoạn khác nhau. Hooks (như useEffect) thay thế chúng trong Function Components.
Tối ưu hóa: shouldComponentUpdate có thể dùng để ngăn re-render không cần thiết, cải thiện hiệu suất.


# 8. Ví dụ thực tế

// Car.js
import React from 'react';

class Car extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      brand: "Toyota",
      color: "blue",
      isRunning: false
    };
  }
  componentDidMount() {
    console.log("Car component mounted");
  }
  toggleEngine = () => {
    this.setState({ isRunning: !this.state.isRunning });
  }
  render() {
    return (
      <div>
        <h1>My {this.props.type} Car</h1>
        <p>It is a {this.state.color} {this.state.brand}.</p>
        <p>Engine: {this.state.isRunning ? "Running" : "Stopped"}</p>
        <button onClick={this.toggleEngine}>
          {this.state.isRunning ? "Stop" : "Start"} Engine
        </button>
      </div>
    );
  }
}
export default Car;

// index.js
import React from 'react';
import ReactDOM from 'react-dom/client';
import Car from './Car';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car type="Sports" />);




# 9. Bài học rút ra 

	- Class Components: Sử dụng class, kế thừa React.Component, cần render().
	- State: Lưu trữ dữ liệu nội bộ, cập nhật bằng this.setState().
	- Props: Truyền dữ liệu từ ngoài vào, truy cập qua this.props.
	- Lifecycle Methods: Quản lý vòng đời (mounting, updating, unmounting).
	- File riêng: Tách component để tái sử dụng.
