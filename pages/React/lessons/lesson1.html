# 1. React là gì? 
	Tóm tắt: React là một thư viện JavaScript mạnh mẽ, được phát triển bởi Facebook, dùng để xây dựng giao diện người dùng (UI) tương tác, đặc biệt là cho các ứng dụng đơn trang (single-page applications - SPA). Nó cho phép tạo các thành phần giao diện (UI components) tái sử dụng, giúp mã nguồn dễ bảo trì và mở rộng.
	
	## Giải thích sâu sắc:
		Thư viện, không phải framework: Khác với Angular hay Vue, React chỉ tập trung vào tầng giao diện (view layer). Điều này mang lại sự linh hoạt, nhưng cũng yêu cầu bạn kết hợp với các công cụ khác (như Redux, React Router) để xây dựng ứng dụng hoàn chỉnh.

		Component-based: React chia nhỏ giao diện thành các "component" (thành phần). Mỗi component là một khối mã độc lập, có thể tái sử dụng, ví dụ: một nút, một form, hoặc một danh sách.
		
		Single-Page Applications (SPA): React giúp xây dựng ứng dụng mà không cần tải lại toàn bộ trang khi người dùng tương tác. Thay vào đó, chỉ các phần giao diện cần thiết được cập nhật, mang lại trải nghiệm mượt mà.
		
		Tư duy khai báo (Declarative): Bạn chỉ cần mô tả giao diện sẽ trông như thế nào, React sẽ tự động cập nhật khi dữ liệu thay đổi, thay vì thao tác thủ công trên DOM như JavaScript truyền thống.
		
	## Tại sao quan trọng? 
		React giúp bạn viết mã nhanh hơn, dễ bảo trì hơn, và tạo ra các ứng dụng tương tác cao với hiệu suất tốt. Nó được sử dụng rộng rãi trong các công ty công nghệ lớn như Facebook, Netflix, và Airbnb.
		
		
# 	2. Ví dụ cơ bản: "Hello World" 
		

import React from 'react';
import ReactDOM from 'react-dom/client';

function Hello(props) {
  return <h1>Hello World!</h1>;
}

const container = document.getElementById("root");
const root = ReactDOM.createRoot(container);
root.render(<Hello />);



	## Giải thích chi tiết: 
	
		### 1. Import thư viện: 
			React: Thư viện chính của React, cần thiết để viết các component.
			ReactDOM: Thư viện phụ để kết nối React với DOM (Document Object Model) của trình duyệt.

		### Component Hello
			function Hello(props): Đây là một functional component, một cách đơn giản để định nghĩa component trong React. Nó nhận props (properties) làm tham số, dù trong ví dụ này chưa sử dụng.
			
			return <h1>Hello World!</h1>: Component trả về mã JSX (JavaScript XML), một cú pháp giống HTML nhưng được 
			xử lý bởi React để tạo ra các phần tử giao diện.
		
		### Render component
			document.getElementById("root"): Lấy phần tử HTML có id="root" trong file index.html. Đây là nơi React sẽ gắn giao diện vào.
			
			ReactDOM.createRoot(container): Tạo một "root" để React quản lý việc render giao diện.
			
			root.render(<Hello />): Hiển thị component Hello lên giao diện, kết quả là một thẻ <h1>Hello World!</h1>.


# 3. Thiết lập môi trường với create-react-app


	## 1 Cài đặt Node.js:
		Đảm bảo bạn đã cài Node.js (bao gồm npm - Node Package Manager).


	## 2. Tạo dự án: 
		Mở terminal, di chuyển đến thư mục mong muốn.
		
		Chạy: npx create-react-app my-react-app.
		
		Lệnh này tạo một dự án React với cấu trúc thư mục sẵn sàng, bao gồm các file như src/App.js, src/index.js, và public/index.html.


	## 3. Chạy ứng dụng:
		Di chuyển vào thư mục dự án: cd my-react-app.
		Chạy: npm start.
		Trình duyệt sẽ mở localhost:3000, hiển thị ứng dụng React mặc định.
		
	


# Lưu ý quan trọng: 
		

	Nếu đã cài create-react-app toàn cục trước đó, hãy gỡ bằng: npm uninstall -g create-react-app để đảm bảo sử dụng phiên bản mới nhất qua npx.
	create-react-app tự động cấu hình các công cụ như Webpack, Babel, và ESLint, giúp bạn tập trung vào viết mã mà không cần lo về cấu hình.


# Sâu sắc hơn:
	npx: Là công cụ chạy các gói npm mà không cần cài đặt toàn cục, đảm bảo bạn luôn dùng phiên bản mới nhất của create-react-app.
	
	Cấu trúc dự án: 
		src/: Chứa mã nguồn React, bao gồm các component và logic.
		public/: Chứa các file tĩnh như index.html.
		package.json: Quản lý các phụ thuộc và script của dự án.

	Hiệu suất: create-react-app tích hợp các tính năng như hot reloading (tự động cập nhật khi thay đổi mã), giúp phát triển nhanh hơn.



# 4. Những gì bạn nên biết trước khi học React

	HTML và CSS: Để tạo và định dạng giao diện.
	JavaScript: Đặc biệt là các tính năng ES6 như:
		Arrow functions: () => {} - cú pháp ngắn gọn cho hàm.
		Destructuring: const { name } = obj - lấy giá trị từ object/array.
		Spread operator: ... - sao chép hoặc hợp nhất dữ liệu.
		Modules: import/export - quản lý mã nguồn.
	JSX: Bạn sẽ học chi tiết trong các bài sau, nhưng cần biết JSX là cách viết giao diện trong React.



# 6. Bài học rút ra

	- React là gì: Một thư viện để xây dựng giao diện tương tác, tập trung vào component và SPA.
	- Component: Đơn vị cơ bản của React, có thể tái sử dụng, viết bằng JSX.
	- Thiết lập môi trường: Sử dụng create-react-app để nhanh chóng bắt đầu dự án.
	- Kiến thức nền: HTML, CSS, JavaScript (đặc biệt ES6) là nền tảng cần thiết.
	- Học chủ động: Thực hành qua ví dụ, làm bài tập, và chạy mã trên máy tính.
