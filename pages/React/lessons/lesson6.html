Lesson 6 -- Component -//


# 1. Components là gì?
	Tóm tắt: Components trong React giống như các hàm JavaScript, nhưng trả về các phần tử HTML (thông qua JSX). Chúng là các khối mã độc lập, có thể tái sử dụng, giúp xây dựng giao diện một cách có tổ chức.	
	
	## Bản chất Components: 
		Components là các đơn vị nhỏ của giao diện, ví dụ: một nút, một tiêu đề, hoặc một danh sách. Mỗi component có thể chứa logic, kiểu dáng (CSS), và dữ liệu riêng.
	
	## Tại sao quan trọng? 
		- Tái sử dụng: Bạn có thể dùng lại component ở nhiều nơi, giảm lặp mã.
		- Tổ chức mã: Chia giao diện thành các phần nhỏ giúp dễ quản lý và bảo trì.
		- Độc lập: Mỗi component hoạt động riêng biệt, không phụ thuộc vào phần còn lại của ứng dụng.		
	
	
	## Hai loại Components: 
		- Class Components: Dựa trên cú pháp class của ES6, sử dụng trước đây nhưng ít phổ biến hơn hiện nay.
		- Function Components: Dùng hàm JavaScript, đơn giản hơn, kết hợp với Hooks (từ React 16.8) là cách được khuyến nghị.		
	
	Quan trọng: Bài học tập trung vào Function Components vì chúng ngắn gọn, dễ hiểu và là chuẩn hiện đại trong React. Class Components chỉ được đề cập như tài liệu tham khảo.
	
# 2. Tạo Component đầu tiên	
	Tóm tắt: Để tạo component, tên phải bắt đầu bằng chữ in hoa. Function Components trả về JSX, còn Class Components cần kế thừa React.Component và có phương thức render().
	
	## 2.1. Function Component
		
function Car() {
  return <h2>Hi, I am a Car!</h2>;
}	
	- Đây là một Function Component đơn giản, trả về thẻ <h2> chứa văn bản.
	- Tên Car bắt đầu bằng chữ in hoa (quy tắc bắt buộc của React để phân biệt component với thẻ HTML thông thường).
	
	### Ưu điểm 
	Cú pháp ngắn gọn, dễ viết và bảo trì.
	Kết hợp tốt với Hooks (như useState, useEffect) để quản lý trạng thái và logic.
	
	### Ví dụ sử dụng 
const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car />);		
	
Component Car được gọi như một thẻ HTML: <Car />.
Kết quả: <h2>Hi, I am a Car!</h2> được hiển thị trong <div id="root">.	
	
	
	
	## 	2.2. Class Component
class Car extends React.Component {
  render() {
    return <h2>Hi, I am a Car!</h2>;
  }
}	
	
	- Kế thừa React.Component để có các tính năng của React (như state, lifecycle methods).
	- Phương thức render() là bắt buộc, trả về JSX.	
	
	- Class Components phức tạp hơn, thường dùng trong các dự án cũ.
	- Function Components với Hooks có thể thay thế hoàn toàn Class Components trong hầu hết trường hợp.	
	
	
	## Sâu sắc hơn: 
		Quy tắc đặt tên: Tên component phải in hoa chữ cái đầu (ví dụ: Car, không phải car) để React phân biệt với thẻ HTML như <div> hoặc <p>.
	
		Function Components là xu hướng: Từ React 16.8, Hooks giúp Function Components xử lý được mọi thứ mà Class Components làm được, nhưng với mã ngắn gọn hơn.


# 3. Rendering Component
	Tóm tắt: Để hiển thị component, bạn gọi nó như một thẻ HTML trong root.render() hoặc trong một component khác.

function Car() {
  return <h2>Hi, I am a Car!</h2>;
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car />);

	root.render(<Car />): Hiển thị component Car trong phần tử <div id="root"> của index.html.

	Kết quả: <h2>Hi, I am a Car!</h2> xuất hiện trên trang.


	## Lưu ý 
		- Component được gọi như thẻ HTML, sử dụng cú pháp <ComponentName />.
		- JSX yêu cầu component phải được định nghĩa trước khi sử dụng.		


	## Sâu sắc hơn:

		- React sử dụng Virtual DOM để so sánh trạng thái trước và sau khi render, chỉ cập nhật những phần thay đổi, giúp tối ưu hiệu suất.
		- Bạn có thể render nhiều component trong cùng một root.render() bằng cách bọc chúng trong một phần tử hoặc Fragment (<></>).



# 4. Props trong Components

	Tóm tắt: Props (properties) là cách truyền dữ liệu vào component, giống như tham số của hàm.


	## Cú pháp:
function Car(props) {
  return <h2>I am a {props.color} Car!</h2>;
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car color="red" />);

	- props: Một object chứa các thuộc tính được truyền vào component (ở đây: { color: "red" }).
	- <Car color="red" />: Truyền thuộc tính color với giá trị "red".
	- Kết quả: <h2>I am a red Car!</h2>.

	## Lợi ích:
		- Props giúp component linh hoạt, có thể hiển thị dữ liệu khác nhau tùy thuộc vào giá trị truyền vào.
		- Tái sử dụng: Một component có thể được dùng ở nhiều nơi với props khác nhau.


	## Sâu sắc hơn:
		- Props là read-only: Bạn không nên thay đổi props bên trong component. Nếu cần trạng thái thay đổi, sử dụng state (sẽ học sau).
		- Props có thể là bất kỳ kiểu dữ liệu nào: chuỗi, số, mảng, object, hoặc thậm chí hàm.


# 5. Components trong Components
	Tóm tắt: Bạn có thể sử dụng một component bên trong một component khác để xây dựng giao diện phức tạp.

	## Ví dụ 
	
function Car() {
  return <h2>I am a Car!</h2>;
}

function Garage() {
  return (
    <>
      <h1>Who lives in my Garage?</h1>
      <Car />
    </>
  );
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Garage />);

	Garage là component cha, chứa component Car.

<h1>Who lives in my Garage?</h1>
<h2>I am a Car!</h2>


	-Lợi ích: Chia nhỏ giao diện thành các component giúp mã dễ quản lý và tái sử dụng.

	- Cây component: React xây dựng giao diện theo dạng cây, với các component lồng nhau (parent-child). Component cha có thể truyền props cho component con.
	
	- Fragment (<></>): Sử dụng Fragment để bọc nhiều phần tử mà không thêm thẻ thừa vào DOM.


# 6. Components trong File riêng 
	Tóm tắt: Để tăng tính tái sử dụng, bạn nên đặt mỗi component trong một file .js riêng và sử dụng import/export để kết nối.


	## Tạo file component:

// Car.js
function Car() {
  return <h2>Hi, I am a Car!</h2>;
}
export default Car;


	- Tên file phải bắt đầu bằng chữ in hoa (theo quy ước).
	- export default: Cho phép component được nhập ở file khác.


	## Sử dụng component: 
// index.js
import React from 'react';
import ReactDOM from 'react-dom/client';
import Car from './Car.js';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Car />);	


	- import Car from './Car.js': Nhập component từ file Car.js.
	- Kết quả tương tự như khi định nghĩa Car trong cùng file.


# 7. Ví dụ thực tế

// Car.js
function Car({ brand, color }) {
  return <h2>I am a {color} {brand}!</h2>;
}
export default Car;

// Garage.js
import Car from './Car';

function Garage() {
  return (
    <>
      <h1>My Garage</h1>
      <Car brand="Toyota" color="blue" />
      <Car brand="Ford" color="red" />
    </>
  );
}
export default Garage;

// index.js
import React from 'react';
import ReactDOM from 'react-dom/client';
import Garage from './Garage';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Garage />);


# 8. Bài học rút ra

	- Components: Là các khối mã độc lập, trả về JSX, giúp xây dựng giao diện tái sử dụng.
	- Function vs Class Components: Function Components đơn giản, được khuyến nghị (kết hợp với Hooks).
	- Props: Truyền dữ liệu vào component để tùy chỉnh nội dung.
	- Components trong Components: Lồng component để tạo giao diện phức tạp.
	- File riêng: Tách component thành các file .js để tổ chức mã tốt hơn.
	- Thực hành: Tạo và sử dụng component với props, lồng component, và tổ chức file.
