Lesson 31 -- useState -//



# 1. Import useState
	Để dùng useState, import từ 'react' (named export, nên dùng destructuring).
		
	import { useState } from "react";  // Import Hook

	{ useState }: Destructuring để lấy trực tiếp, tránh React.useState. ES6 destructuring giúp code sạch. Nếu dùng TypeScript, không cần thêm types (React types built-in).


	Insight chuyên gia: Luôn import ở top file. Trong bundlers như Vite/CRA, tree-shaking loại bỏ unused imports. Lỗi phổ biến: Quên import dẫn đến "useState is not defined". Best practice: Sử dụng ESLint rule react-hooks/rules-of-hooks để enforce Hooks rules.

	useState là entry point cho state management, nhưng trong app lớn, kết hợp với useReducer cho state phức tạp hoặc Redux/Zustand cho global state. React batch updates setters để optimize performance (từ v16), async nature giúp tránh race conditions. Nhược điểm: Overuse có thể gây re-renders thừa; best practice: Giữ state minimal, local, và dùng React.memo cho components con. Trong React 18+, useState hỗ trợ Concurrent Rendering, cho phép interrupt updates. Nếu state phụ thuộc props, dùng derived state hoặc useMemo.


# 2. Initialize useState 
	
	Gọi useState ở top level functional component để khởi tạo state. Nhận initial value, trả về [current state, setter function].

import { useState } from "react";

function FavoriteColor() {
  const [color, setColor] = useState("red");  // Khởi tạo
}


	- useState("red"): Initial value ("red") chỉ gọi lần đầu (mount). Trả về array để destructuring: [state, setState].
	- color: Current value (read-only).
	- setColor: Setter để update (async, batchable).
	- Tên variable linh hoạt (ví dụ: [count, setCount]), nhưng convention: set + state name.

	Insight chuyên gia: Initial value có thể là function cho lazy init (expensive computations): useState(() => fetchInitial()) – chỉ chạy lần đầu. Trong SSR (Next.js), initial value phải serializable. Best practice: Khởi tạo state ở top level, không conditional (vi phạm Hooks rules).



# 3. Read State

	Sử dụng state variable trực tiếp trong JSX để render.

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function FavoriteColor() {
  const [color, setColor] = useState("red");  // State

  return <h1>My favorite color is {color}!</h1>;  // Read state
}

createRoot(document.getElementById('root')).render(
  <FavoriteColor />
);


	- {color}: Interpolation state vào JSX. Re-render khi state thay đổi.
	- Render: Mount vào DOM với createRoot (React 18+).

	State là local, reactive – thay đổi trigger reconcile. Nếu state lớn, dùng useMemo để memoize derived values (ví dụ: const upperColor = useMemo(() => color.toUpperCase(), [color])). Debug: Xem state trong React DevTools



# 4. Update State

	Sử dụng setter để update, không mutate trực tiếp (ví dụ: không color = "blue"). Setter trigger re-render.


import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function FavoriteColor() {
  const [color, setColor] = useState("red");

  return (
    <>
      <h1>My favorite color is {color}!</h1>
      <button type="button" onClick={() => setColor("blue")}>Blue</button>  // Update
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <FavoriteColor />
);


	onClick={() => setColor("blue")}: Arrow function gọi setter với value mới.
	Setter async: Không thấy thay đổi ngay (dùng callback nếu cần immediate read).

	Insight chuyên gia: Không mutate state trực tiếp để tránh side effects (React shallow compares). Functional updates cho phụ thuộc state cũ: setColor(prev => prev + "ish"). Batch: Nhiều setters cùng event loop chỉ re-render once. Lỗi: Infinite loops nếu setter trong render (di chuyển vào event handlers hoặc useEffect).


# 5. What Can State Hold?

	useState hỗ trợ bất kỳ type: strings, numbers, booleans, arrays, objects, hoặc kết hợp. Có thể nhiều Hooks riêng lẻ hoặc một object.

import { useState } from 'react';
import { createRoot } from 'react-dom/client';

function MyCar() {
  const [brand, setBrand] = useState("Ford");
  const [model, setModel] = useState("Mustang");
  const [year, setYear] = useState("1964");
  const [color, setColor] = useState("red");

  return (
    <>
      <h1>My {brand}</h1>
      <p>It is a {color} {model} from {year}.</p>
    </>
  );
}

createRoot(document.getElementById('root')).render(
  <MyCar />
);

# 6. Updating Objects and Arrays in State

	Update overwrite toàn state, nên dùng spread (...) để copy và chỉ thay đổi phần cần.

const updateColor = () => {
  setCar(previousState => {  // Functional update
    return { ...previousState, color: "blue" };  // Spread + override
  });
};

setCar(previousState => ...): Callback nhận prev state (an toàn cho async).
{ ...previousState, color: "blue" }: Shallow copy, override color. Giữ brand/model/year.


	Insight chuyên gia: Đối với arrays: setList(prev => [...prev, newItem]) hoặc prev.filter(...). Deep updates: Dùng nested spread { ...prev, nested: { ...prev.nested, key: value } }. Nếu mutate (push trực tiếp), React không detect, dẫn đến stale UI. Best practice: Dùng useImmer cho mutable-like syntax. Performance: Nếu object lớn, xem xét normalize state (flat structures).



	## Ví dụ mở rộng:
	
const [list, setList] = useState([1, 2, 3]);
const addItem = () => setList(prev => [...prev, 4]);  // [1,2,3,4]
const removeLast = () => setList(prev => prev.slice(0, -1));  // Không mutate
