# 1 What is a Higher Order Component?  HOC 

	HOC là hàm (function) nhận component làm input và trả về component mới với enhancement. Không modify component gốc, mà compose (kết hợp) để thêm feature. Useful cho:
	
	- Thêm props (props proxy): Inject data hoặc functions.
	- Manipulate rendering (render hijacking): Thay đổi JSX output.
	- Inheritance inversion: Kế thừa từ component gốc để override.	
	
	Note từ bài: HOCs có thể thay bằng Hooks, nhưng vẫn useful cho auth hoặc data fetching.
	
	Insight chuyên gia: HOC lấy cảm hứng từ Higher-Order Functions trong functional programming (JS). Trong React, giúp DRY (Don't Repeat Yourself) bằng cách abstract logic chung. Ví dụ: Một HOC cho loading spinner có thể wrap nhiều components. Lỗi phổ biến: Quên spread props dẫn đến mất data; luôn dùng {...props}. Trong TypeScript, khai báo HOC với generics để type-safe: function withBorder<P>(Wrapped: ComponentType<P>): ComponentType<P> { ... }. Nếu dùng nhiều HOC, chain chúng (compose) với thư viện như recompose (dù giờ ít dùng).
	
	
# 2. Example: Adding a Border
	
	Ví dụ tạo HOC withBorder để thêm border xanh cho bất kỳ component nào, minh họa tính reusable.
	
// This is our HOC - it adds a border to any component
function withBorder(WrappedComponent) {  // HOC nhận component gốc
  return function NewComponent(props) {  // Trả về component mới
    return (
      <div style={{ border: '2px solid blue', padding: '10px' }}>  // Wrap với div có style
        <WrappedComponent {...props} />  // Render component gốc, truyền props
      </div>
    );
  };
}

// Simple component without border
function Greeting({ name }) {  // Component gốc đơn giản
  return <h1>Hello, {name}!</h1>;
}

// Create a new component with border
const GreetingWithBorder = withBorder(Greeting);  // Áp dụng HOC để tạo version mới

function App() {
  return (
    <div>
      <Greeting name="John" />  // Sử dụng gốc: Không border
      <GreetingWithBorder name="Jane" />  // Sử dụng enhanced: Có border
    </div>
  );
}
	
	- function withBorder(WrappedComponent): Định nghĩa HOC, nhận component gốc làm tham số.
	- return function NewComponent(props): Trả về một functional component mới (anonymous function), nhận props từ cha.
	- <div style={{ border: '2px solid blue', padding: '10px' }}>: Thêm wrapper DOM với inline style (có thể dùng className cho CSS external).
	- <WrappedComponent {...props} />: Render component gốc, spread props để truyền tất cả prop xuống (giữ nguyên behavior, ví dụ: name prop).
	- const GreetingWithBorder = withBorder(Greeting);: Tạo component enhanced bằng cách gọi HOC với Greeting.
	- Trong App(): Sử dụng cả hai version để chứng minh tính linh hoạt – gốc không thay đổi.
	
	
	## Insight chuyên gia: Ví dụ này là props proxy đơn giản (thêm props gián tiếp qua wrapper). Trong thực tế, mở rộng để dynamic: Truyền props vào HOC (curried HOC):
	
function withBorder(color = 'blue') {  // Tham số cho HOC
  return (WrappedComponent) => (props) => (
    <div style={{ border: `2px solid ${color}`, padding: '10px' }}>
      <WrappedComponent {...props} />
    </div>
  );
}
const GreetingWithRedBorder = withBorder('red')(Greeting);	
	
	
		
	##	 Ví dụ mở rộng để học: 
	
	function withAuth(WrappedComponent) {
  return (props) => {
    const [isAuthenticated, setIsAuthenticated] = useState(false);  // Giả lập auth state
    useEffect(() => { setIsAuthenticated(true); }, []);  // Check auth
    if (!isAuthenticated) return <div>Login required</div>;
    return <WrappedComponent {...props} />;
  };
}
const ProtectedGreeting = withAuth(Greeting);
	
	
	
	
	
# 	3. Example Explained
	
	- withBorder là HOC: Nhận component, trả về mới.
	- Wrapper thêm div border.
	- Component gốc (Greeting) không thay đổi.
	- Sử dụng cả hai version song song.
	
	Note từ bài: HOCs thay thế được bằng Hooks, nhưng useful cho patterns như auth/data fetching.
	
	Insight chuyên gia: Trong v18+, dùng custom hooks cho logic tương tự (ví dụ: useBorder return { wrapperStyle }, áp dụng trong component). Nhưng HOCs tốt hơn cho class components hoặc khi cần manipulate children (render hijacking). Trong libraries, HOCs giúp backward compatibility. Debug tip: Sử dụng React Profiler để check re-renders do HOC gây ra.
