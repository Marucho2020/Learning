Lesson 30 -- ng-switch -//

# Khái niệm 
	Directive ng-switch trong AngularJS cho phép bạn hiển thị có điều kiện các phần tử HTML khác nhau dựa trên giá trị của một biểu thức — tương tự như câu lệnh switch trong JavaScript, nhưng dùng cho HTML template.

# 🧠 Cách hoạt động tổng quát
	ng-switch được đặt trên phần tử container (thường là <div>).
	Bên trong đó, bạn dùng ng-switch-when="value" để xác định khối sẽ được hiển thị khi biểu thức trong ng-switch có giá trị tương ứng.
	
# ✅ Cú pháp
<div ng-switch="expression">
  <div ng-switch-when="value1">Hiển thị nếu expression == value1</div>
  <div ng-switch-when="value2">Hiển thị nếu expression == value2</div>
  <div ng-switch-default>Hiển thị nếu không trùng value nào</div>
</div>

# 📘 Ví dụ đơn giản
<div ng-app="myApp" ng-controller="myCtrl">
  <select ng-model="selectedColor">
    <option value="red">Đỏ</option>
    <option value="blue">Xanh</option>
    <option value="green">Xanh lá</option>
  </select>

  <div ng-switch="selectedColor">
    <p ng-switch-when="red">Bạn chọn màu đỏ.</p>
    <p ng-switch-when="blue">Bạn chọn màu xanh dương.</p>
    <p ng-switch-when="green">Bạn chọn màu xanh lá.</p>
    <p ng-switch-default>Chưa chọn màu nào.</p>
  </div>
</div>

>> js 
angular.module('myApp', []).controller('myCtrl', function($scope) {
  $scope.selectedColor = "";
});


# 🔍 Giải thích chi tiết
| Thuộc tính               | Ý nghĩa                                       |
| ------------------------ | --------------------------------------------- |
| `ng-switch="expression"` | Giá trị để so sánh                            |
| `ng-switch-when="value"` | Render phần tử nếu `expression === value`     |
| `ng-switch-default`      | Render nếu không có `ng-switch-when` nào khớp |



# 💡 Ưu điểm so với ng-if hoặc ng-show
	ng-switch giúp tổ chức logic nhiều điều kiện phân nhánh phức tạp một cách rõ ràng, dễ đọc hơn.
	Tránh phải viết nhiều ng-if, dẫn đến lặp code.
	Hiệu suất tốt hơn nếu có nhiều khối rẽ nhánh cần loại bỏ hoàn toàn khỏi DOM khi không được chọn.

# ⚠️ Lưu ý

	Chỉ một phần tử con trong ng-switch được hiển thị tại một thời điểm.
	Các phần tử con phải là sibling (cùng cấp con của phần tử ng-switch).

# 🧠 Tóm lại:

| Điểm mạnh của `ng-switch`                    |
| -------------------------------------------- |
| Gọn gàng hơn nhiều `ng-if`                   |
| Tương tự `switch-case` trong JS              |
| Dễ đọc và mở rộng logic hiển thị             |
| Có thể thêm `ng-switch-default` làm fallback |
