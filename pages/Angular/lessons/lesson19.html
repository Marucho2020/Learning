Lesson 19 -- AngularJS API -//

# Khái niệm  
	
	AngularJS cung cấp một số API (Application Programming Interface) – tức là các phương thức và đối tượng có sẵn giúp bạn thao tác, xử lý dữ liệu và điều khiển luồng logic trong Angular dễ dàng hơn.


# ⚙️ Một số API phổ biến: 
	## 1. $http – Gửi HTTP request (AJAX)
		Dùng để gửi request tới backend (GET, POST, PUT, DELETE...) 
		
		$http.get("data.txt").then(function(response) {
			$scope.content = response.data;
		});


	| Method         | Ý nghĩa                  |
	| -------------- | ------------------------ |
	| `$http.get()`  | Lấy dữ liệu              |
	| `$http.post()` | Gửi dữ liệu              |
	| `.then()`      | Callback khi có response |




	## 	 2. $timeout – Delay một đoạn code (như setTimeout trong JS)

		$timeout(function() {
			$scope.message = "3 giây sau mới hiện!";
		}, 3000);
		Tương đương setTimeout() nhưng được tích hợp với Angular để trigger $digest cycle (cập nhật view).


	## 3. $interval – Lặp định kỳ (như setInterval)

			$interval(function() {
				$scope.time = new Date().toLocaleTimeString();
			}, 1000);
			Dùng để tạo đồng hồ, cập nhật realtime,…


	## 4. $location – Lấy & điều hướng URL 
		$location.path('/home');
		
		.path() để lấy hoặc chuyển path.
		Dùng để redirect trang trong SPA (Single Page Application). 


	## $watch() – Theo dõi sự thay đổi của biến 
	
		$scope.$watch('userInput', function(newVal, oldVal) {
			console.log('Giá trị mới:', newVal);
		});
		
		Nếu userInput thay đổi, callback sẽ được gọi tự động.


	## 6. $apply() – ép Angular kiểm tra lại view (ít khi dùng) 
		$scope.$apply(function(){
			$scope.value = "Thay đổi từ bên ngoài Angular";
		});
	

# 🔍 So sánh với JavaScript truyền thống:
| Mục tiêu      | JS truyền thống              | AngularJS API |
| ------------- | ---------------------------- | ------------- |
| Gửi GET       | `fetch()` / `XMLHttpRequest` | `$http.get()` |
| Delay         | `setTimeout()`               | `$timeout()`  |
| Đồng hồ       | `setInterval()`              | `$interval()` |
| Theo dõi biến | Tự xử lý                     | `$watch()`    |


# 🧠 Kết luận 
	AngularJS API giúp code gọn hơn, dễ duy trì hơn, tích hợp sẵn với hệ thống binding của framework.
	Cần hiểu rõ các khái niệm như $http, $timeout, $watch, $scope... để viết Angular hiệu quả.
