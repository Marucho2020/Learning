Lesson 20 -- W3.CSS -//

# Khái niệm  
	 Đây là bài nói về việc kết hợp AngularJS với W3.CSS, một framework CSS nhẹ của W3Schools. Mặc dù không phải phần cốt lõi của AngularJS, nhưng hiểu bài này giúp bạn làm giao diện đẹp hơn khi xây dựng ứng dụng AngularJS.
	 
		Một framework CSS nhẹ, không phụ thuộc vào JavaScript.
		Do W3Schools phát triển.
		Dễ dùng, nhẹ, thiết kế theo chuẩn responsive.
		Thay thế cho Bootstrap nếu bạn chỉ cần giao diện đơn giản, nhanh gọn.
	
# Cách sử dụng W3.CSS trong AngularJS
	
1. Thêm link đến W3.CSS
	<link rel="stylesheet" href="https://www.w3schools.com/w3css/4/w3.css">

2. Dùng class của W3.CSS để style UI
>> html 
<div ng-app="myApp" ng-controller="myCtrl" class="w3-container">
  <h1 class="w3-text-blue">Hello {{ name }}</h1>
  <input class="w3-input" ng-model="name">
</div>

>> controller 
angular.module('myApp', []).controller('myCtrl', function($scope) {
  $scope.name = "Bảo";
});



# 🎨 Một số class W3.CSS hữu ích:
| Class                     | Tác dụng                     |
| ------------------------- | ---------------------------- |
| `w3-container`            | Tạo phần tử có padding chuẩn |
| `w3-input`                | Styling input đẹp            |
| `w3-button`               | Button đơn giản, dễ nhìn     |
| `w3-blue`, `w3-red`       | Màu sắc nền                  |
| `w3-card`                 | Tạo khối nổi dạng card       |
| `w3-text-color`           | Màu chữ                      |
| `w3-margin`, `w3-padding` | Khoảng cách layout           |

# 📦 Khi nào dùng W3.CSS? 
| Trường hợp                    | Có nên dùng?                                                   |
| ----------------------------- | -------------------------------------------------------------- |
| Làm prototype nhanh, đơn giản | ✅ Nên                                                          |
| Web nội bộ, tool nhỏ          | ✅ Nên                                                          |
| App lớn, cần UI tùy biến cao  | ❌ Không nên → Chuyển sang Tailwind, Bootstrap, hoặc viết riêng |

	| Ưu điểm            | Nhược điểm                        |
| ------------------ | --------------------------------- |

| Gọn, nhanh dựng UI | Không có nhiều component phức tạp |
