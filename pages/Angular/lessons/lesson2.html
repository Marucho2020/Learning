Lesson 2 -- AngularJS Expression -//

# Khái niệm 
	AngularJS Expressions là cú pháp cho phép bạn gắn dữ liệu hoặc thực hiện phép tính ngay trong HTML bằng dấu
		{{ ... }}. 	
		
	Giống như "mini-JavaScript" nhưng chạy bên trong AngularJS, và không cần viết trong script hay controller.	
	
	
	
# 	🔍 Cú pháp cơ bản: 
	
	<p>{{ 5 + 5 }}</p>         <!-- In ra: 10 -->
	<p>{{ firstName + " " + lastName }}</p>   <!-- Ghép chuỗi -->
	<p>{{ quantity * price }}</p>             <!-- Phép toán -->
	
	
	
# 	⚖️ So sánh AngularJS Expression vs JavaScript thông thường 
	
| So sánh        | AngularJS Expression                                 | JavaScript                      |
| -------------- | ---------------------------------------------------- | ------------------------------- |
| Cú pháp        | `{{ expression }}` trong HTML                        | Viết trong `<script>`           |
| Quyền truy cập | Truy cập biến trong `$scope`                         | Truy cập biến global hoặc local |
| Đặc tính       | Không dùng `condition`, `loop`, `function` trực tiếp | Có thể dùng tất cả              |
| Bảo mật        | Bị giới hạn để tránh lạm dụng                        | Mạnh, nhưng dễ gây lỗi          |
	
➡️ Ý nghĩa: AngularJS expression chỉ dành cho xử lý đơn giản hiển thị trên View.


# 	⚠️ Những giới hạn: 
	
		- Không thể khai báo biến (var, let, const)
		- Không gọi hàm JavaScript bên ngoài nếu không có trong $scope
		- Không thực hiện lệnh điều kiện (if, switch), chỉ biểu thức logic (&&, ||, !, ==, !=...)	
	
	
# 	💡 Ví dụ phổ biến trong thực tế: 
	<!-- Gán trong controller -->
	$scope.firstName = "Bảo";
	$scope.lastName = "Nguyễn";
	
	<!-- HTML -->
	<p>Họ tên: {{ firstName + " " + lastName }}</p>
	<p>Giảm giá 10%: {{ price * 0.9 }}</p>
	<p>Có giảm giá? {{ price > 100000 }}</p> <!-- true/false -->
	
		
	## Ví dụ 2 
		$scope.name = "Bảo";
		$scope.price = 100;
		$scope.discounted = function() {
		return $scope.price * 0.9;
		};
		
		-> trong HTML sử dụng  
		<p>{{ name }}</p>                <!-- Bảo -->
		<p>{{ price * 0.9 }}</p>         <!-- 90 -->
		<p>{{ discounted() }}</p>       <!-- 90 -->

	
	### 🛡️ Bạn không thể làm:
	
	{{ alert('hello') }}         ❌ không được (ngoài scope)
	{{ window.location }}        ❌ không được
	{{ var x = 5 }}              ❌ không được khai báo biến

	
# 📌 Kết luận:
	{{ ... }} giống như một lối tắt gắn dữ liệu và logic đơn giản vào HTML.
	Dễ dùng, hiệu quả, nhưng nên dùng đúng mức – khi xử lý logic phức tạp thì đưa về controller.
