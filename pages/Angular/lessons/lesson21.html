Lesson 21 -- Includes -//

# Khái niệm 
	cách bạn có thể "nhúng" (include) file HTML khác vào trong trang HTML chính bằng cách dùng AngularJS.
	Đây là một kỹ thuật rất quan trọng trong AngularJS vì nó cho phép bạn chia nhỏ giao diện thành từng phần (modular UI) – dễ bảo trì, dễ tái sử dụng, và dễ mở rộng. 

# 🔧 Cú pháp chính: ng-include
	<div ng-include="'filename.html'"></div>
	
	ng-include là một directive của AngularJS.
	Nhận vào chuỗi tên file HTML, đặt trong ' '.
	Angular sẽ load nội dung của file đó và chèn vào DOM tại vị trí này.
	
# 📦 Ví dụ:
	Giả sử bạn có 3 file:
	📄 footer.html
	📄 header.html
	
	📄 main.html
	<!DOCTYPE html>
<html ng-app="">
  <body>

    <div ng-include="'header.html'"></div>

    <h1>Trang chính</h1>
    <p>Nội dung chính ở đây</p>

    <div ng-include="'footer.html'"></div>

  </body>
</html>

	
	➡️ Khi chạy main.html, Angular sẽ load file header.html và footer.html rồi hiển thị nội dung tại chỗ có ng-include.



# 📌 Có thể dùng biến thay vì tên cứng
	Bạn có thể bind file động:


>> html 
<div ng-include="templateUrl"></div>

>> js 
$scope.templateUrl = "header.html";

→ Thay đổi templateUrl sẽ thay đổi nội dung được include.


# ✅ Tóm tắt:
| Mục đích                        | Giải thích                        |
| ------------------------------- | --------------------------------- |
| Tái sử dụng giao diện           | Tách header, footer, menu…        |
| Dễ bảo trì                      | Sửa một lần dùng nhiều nơi        |
| Kết hợp controller, scope riêng | Dễ mở rộng (khi tách theo module) |


# ⚠️ Lưu ý:

	File include phải cùng domain (nếu không, bị chặn CORS).
	Nội dung trong file được include vẫn có thể dùng AngularJS bình thường (biến, binding, v.v.).
	Nếu cần truyền dữ liệu vào file được include, phải xử lý bằng scope chung hoặc directive riêng.


# 🧠 Kết luận:
	Dùng ng-include giúp bạn chia nhỏ giao diện → code sạch hơn, có tổ chức.
	Nếu bạn quen với các framework như React/Angular 2+, thì ng-include chính là tổ tiên sơ khai của Component hóa UI.
	Nếu bạn đang build hệ thống nội bộ hoặc web tool dạng SPA (Single Page App), thì dùng ng-include sẽ giúp tăng tốc phát triển rất nhiều.
