Lesson 46 -- $data -//


# Khái niệm 
	Trong Vue.js (bao gồm Vue 3), $data là một thuộc tính đặc biệt của instance component, chứa object dữ liệu (data object) được định nghĩa trong tùy chọn data của component. Nó cung cấp quyền truy cập trực tiếp vào các thuộc tính dữ liệu phản hồi (reactive data) của component.
	
	
# 	Điểm chính về $data 
	Chức năng: $data là một object chứa tất cả các thuộc tính được khai báo trong hàm data (hoặc object data) của component.
	
	Phản hồi (Reactivity): Các thuộc tính trong $data được Vue theo dõi để tự động cập nhật giao diện khi thay đổi.
	
	Cách sử dụng: Có thể truy cập $data trong instance component (qua this.$data) để đọc hoặc sửa đổi dữ liệu.

		

# Ví dụ 

<template>
  <div>{{ message }}</div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Hello Vue!'
    };
  },
  mounted() {
    console.log(this.$data); // { message: 'Hello Vue!' }
    this.$data.message = 'Updated!'; // Cập nhật giá trị phản hồi
  }
};
</script>


# Lưu ý
	-$data chỉ chứa các thuộc tính được khai báo trong data. Các thuộc tính động thêm vào sau không được phản hồi trừ khi dùng Vue.set (Vue 2) hoặc đảm bảo trong data (Vue 3).
	-Trong Vue 3, $data vẫn hoạt động nhưng việc quản lý trạng thái thường được khuyến khích sử dụng Composition API với ref hoặc reactive thay vì Options API.
	-Tóm lại, $data là cách truy cập dữ liệu phản hồi của component, hữu ích khi cần thao tác trực tiếp với object dữ liệu trong Options API.
