Lesson 11 -- modifiers -//


# Khái niệm 
	Event modifiers là các hậu tố (suffix) được thêm vào v-on (hoặc @) để điều chỉnh cách xử lý sự kiện, giảm mã JavaScript thủ công.
	Cú pháp: @sự-kiện.modifier="hàm".
	Mục đích: Xử lý các hành vi sự kiện phổ biến như ngăn tải lại trang, dừng lan truyền sự kiện, hoặc giới hạn kích hoạt.
	
	


# Ví dụ cơ bản: 
<div id="app">
  <form @submit.prevent="onSubmit">
    <button type="submit">Submit</button>
  </form>
</div>

<script>
const app = Vue.createApp({
  methods: {
    onSubmit() {
      alert('Form submitted!');
    }
  }
})
app.mount('#app')
</script>


		## Giải thích: 
			@submit.prevent: Ngăn hành vi mặc định của form (tải lại trang) và gọi hàm onSubmit.



# 2. Các Event Modifiers phổ biến


	## a.prevent 
		Ngăn hành vi mặc định (như submit form, nhảy link). Ví dụ:
		
		<a @click.prevent="doSomething" href="https://example.com">Click me</a>
		Ngăn nhảy link, chỉ gọi doSomething.
		
		
	## b. stop 

<div @click="parentClick">
  <button @click.stop="childClick">Click me</button>
</div>
	Chỉ gọi childClick, không gọi parentClick.


	## c. once
		Sự kiện chỉ kích hoạt một lần. Ví dụ:
		doOnce chỉ chạy lần đầu tiên nhấn.
		
		<button @click.once="doOnce">Click once</button>

		

	## d.capture
		Xử lý sự kiện ở giai đoạn capture (trước bubbling). Ví dụ:
		<div @click.capture="doThis">...</div>
		
		

	## e. self 
		Chỉ kích hoạt nếu sự kiện xảy ra trên chính phần tử đó. Ví dụ:
		<div @click.self="doThis">...</div>
		
		

	## f. Key Modifiers
		Gắn với phím cụ thể, như .enter, .space. Ví dụ:
		<input @keyup.enter="submit">
		Gọi submit khi nhấn phím Enter.
