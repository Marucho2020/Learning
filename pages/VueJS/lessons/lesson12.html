# Khái niệm 			
	Forms và v-model trong Vue.js
		v-model: Directive tạo liên kết hai chiều (two-way data binding) giữa dữ liệu trong Vue (data) và các phần tử nhập liệu như <input>, <textarea>, <select>.
		
		Mục đích: Đồng bộ giá trị của form với dữ liệu reactive, tự động cập nhật khi người dùng nhập hoặc dữ liệu thay đổi.
		
		Cú pháp: v-model="biến".


Ví dụ cơ bản: 
<div id="app">
  <input v-model="message" placeholder="Type here">
  <p>Message: {{ message }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      message: ''
    }
  }
})
app.mount('#app')
</script>


# 2. Các loại phần tử form với v-model

	##a. Text Input
		Dùng v-model với <input type="text"> hoặc <textarea>. Ví dụ:
		
<div id="app">
  <textarea v-model="description"></textarea>
  <p>{{ description }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      description: ''
    }
  }
})
app.mount('#app')
</script>


	## b. Checkbox 
		v-model với <input type="checkbox"> quản lý trạng thái true/false hoặc mảng (cho nhiều checkbox). Ví dụ: 
		
<div id="app">
  <input type="checkbox" v-model="isChecked">
  <p>Checked: {{ isChecked }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      isChecked: false
    }
  }
})
app.mount('#app')
</script>		


>> Mảng checkbox:

<div id="app">
  <input type="checkbox" value="Apple" v-model="fruits">
  <input type="checkbox" value="Banana" v-model="fruits">
  <p>Selected: {{ fruits }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      fruits: []
    }
  }
})
app.mount('#app')
</script>
fruits là mảng chứa các giá trị được chọn (như ['Apple', 'Banana']).
	
	
	## c. Radio Buttons
v-model liên kết với một giá trị duy nhất. Ví dụ:

<div id="app">
  <input type="radio" value="Yes" v-model="answer">
  <input type="radio" value="No" v-model="answer">
  <p>Answer: {{ answer }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      answer: ''
    }
  }
})
app.mount('#app')
</script>


	## d. Select
		v-model quản lý giá trị được chọn trong <select>. Ví dụ:
		
<div id="app">
  <select v-model="selected">
    <option>Apple</option>
    <option>Banana</option>
    <option>Orange</option>
  </select>
  <p>Selected: {{ selected }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      selected: ''
    }
  }
})
app.mount('#app')
</script>		




# 3. Kết hợp với v-on và Form Submission

	## Dùng @submit.prevent để xử lý gửi form mà không tải lại trang. Ví dụ: 
<div id="app">
  <form @submit.prevent="submitForm">
    <input v-model="name" placeholder="Enter name">
    <button type="submit">Submit</button>
  </form>
  <p>{{ name }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      name: ''
    }
  },
  methods: {
    submitForm() {
      alert('Submitted: ' + this.name);
    }
  }
})
app.mount('#app')
</script>
