Lesson 10 -- Methods -//


# Khái niệm  
	Methods là các hàm được định nghĩa trong đối tượng methods của Vue instance, dùng để xử lý logic, tương tác người dùng, hoặc cập nhật dữ liệu.
	Cách sử dụng: Gọi trong template (qua v-on hoặc biểu thức) hoặc trong các phương thức khác
	Ngữ cảnh: Trong methods, this trỏ đến Vue instance, cho phép truy cập data, computed, hoặc các methods khác.
	
	
# 	Ví dụ 
<div id="app">
  <button @click="increment">Click me</button>
  <p>Count: {{ counter }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      counter: 0
    }
  },
  methods: {
    increment() {
      this.counter++;
    }
  }
})
app.mount('#app')
</script>	


	## Giải thích: 
		increment là phương thức trong methods, tăng counter khi nút được nhấn (@click).
		this.counter truy cập thuộc tính reactive trong data().


# 2. Các đặc điểm của Methods


	## a. Gọi trong Template 
		Dùng với v-on (như @click="increment") hoặc trong biểu thức ({{ myMethod() }}). Ví dụ:
	
<div id="app">
  <p>{{ greet() }}</p>
</div>

<script>
const app = Vue.createApp({
  methods: {
    greet() {
      return 'Hello Vue!';
    }
  }
})
app.mount('#app')
</script>

			-> greet() trả về chuỗi hiển thị trong <p>.

	
	
	
	## 	b. Truy cập data và các phương thức khác
		Trong methods, this cho phép truy cập dữ liệu reactive hoặc gọi các phương thức khác. Ví dụ:
		
<div id="app">
  <button @click="updateMessage">Update</button>
  <p>{{ message }}</p>
</div>

<script>
const app = Vue.createApp({
  data() {
    return {
      message: 'Hello'
    }
  },
  methods: {
    updateMessage() {
      this.message = this.getNewMessage();
    },
    getNewMessage() {
      return 'Hello Vue!';
    }
  }
})
app.mount('#app')
</script>	
		
		
		
		
		
	## c. Nhận tham số 		
		Phương thức có thể nhận tham số từ sự kiện hoặc template. Ví dụ:

<div id="app">
  <button @click="say('Hi')">Say Hi</button>
</div>

<script>
const app = Vue.createApp({
  methods: {
    say(message) {
      alert(message);
    }
  }
})
app.mount('#app')
</script>
