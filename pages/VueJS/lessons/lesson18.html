# Khái niệm 
	Single-File Component (SFC) đầu tiên trong Vue.js, sử dụng file .vue và công cụ xây dựng như Vite. Đây là bước tiếp theo sau bài về mở rộng ứng dụng Vue, tập trung vào thực hành tạo và sử dụng SFC. Dưới đây là giải thích ngắn gọn, súc tích, và kết nối với các bài trước (scale-up, templates, computed, v.v.). 
	
	
# 	1. Single-File Component (SFC) là gì?

	## SFC là file có đuôi .vue, gộp ba phần 
		<template>: HTML cho giao diện, dùng các directive như v-bind, v-for.
		<script>: JavaScript cho logic (bao gồm data, methods, computed, v.v.).
		<style>: CSS cho kiểu dáng, có thể thêm scoped để chỉ áp dụng cho component.
		
	Mục đích: Tổ chức code theo component, dễ bảo trì và tái sử dụng trong dự án lớn.	
	
	Ví dụ SFC cơ bản (HelloWorld.vue):
<template>
  <h1>{{ message }}</h1>
</template>

<script>
export default {
  data() {
    return {
      message: 'Hello, Vue SFC!'
    }
  }
}
</script>

<style scoped>
h1 {
  color: green;
}
</style>	
	
	
Giải thích:
	<template>: Hiển thị message bằng interpolation ({{ message }}).
	<script>: Xuất một đối tượng Vue với data chứa message.
	<style scoped>: CSS chỉ áp dụng cho component này, không ảnh hưởng component khác.	
	


# Cách tạo và sử dụng SFC

	## a. Tạo dự án với Vite
		Chạy lệnh để tạo dự án Vue
		Chạy lệnh để tạo dự án Vue
	
	Chọn các tùy chọn (như Vue 3, JavaScript/TypeScript), sau đó
	npm install
	npm run dev
	Dự án tạo sẵn file App.vue và thư mục components/ chứa các file .vue như HelloWorld.vue.

	## b. Sử dụng SFC
	Import và sử dụng component trong file .vue khác. Ví dụ (App.vue):
<template>
  <HelloWorld />
</template>

<script>
import HelloWorld from './components/HelloWorld.vue';

export default {
  components: {
    HelloWorld
  }
}
</script>

Giải thích:
import HelloWorld: Nhập component từ file HelloWorld.vue.
components: { HelloWorld }: Đăng ký component để sử dụng trong template.
<HelloWorld />: Sử dụng component trong <template>.
