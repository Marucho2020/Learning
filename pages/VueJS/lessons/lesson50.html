Lesson 50 -- v-cloak -//


# Khái niệm 
	Thuộc tính v-cloak trong Vue.js (bao gồm Vue 3) là một directive được sử dụng để ẩn một phần tử DOM cho đến khi instance Vue hoàn tất việc biên dịch (compile) template, nhằm tránh hiện tượng nhấp nháy nội dung chưa được render (FOUC - Flash of Uncompiled Content).
	
	
# 	Cách hoạt động 
	
	v-cloak được thêm vào phần tử trong template.
	
	Vue tự động thêm CSS [v-cloak] { display: none; } để ẩn phần tử cho đến khi quá trình biên dịch hoàn tất.
	
	Khi Vue hoàn tất render, directive v-cloak được gỡ bỏ, và phần tử trở nên hiển thị.
	
	
# 	Ví dụ 
<style>
[v-cloak] {
  display: none;
}
</style>

<div v-cloak>
  {{ message }}
</div>

<script>
export default {
  data() {
    return {
      message: 'Hello Vue!'
    };
  }
};
</script>	
	
	Giải thích: <div> sẽ bị ẩn cho đến khi Vue render xong {{ message }}, tránh hiển thị nội dung thô như {{ message }} trong lúc tải.
	
	## Lưu ý 
		CSS bắt buộc: v-cloak chỉ hoạt động nếu có CSS [v-cloak] { display: none; }.
		
		Chủ yếu cho SPA: Hữu ích trong các ứng dụng một trang (SPA) hoặc khi tải JavaScript chậm.
		
		Vue 3: v-cloak hoạt động tương tự như Vue 2, không có thay đổi lớn.
		
		Thay thế: Trong SSR (Server-Side Rendering) hoặc các ứng dụng lớn, các kỹ thuật như pre-rendering hoặc skeleton loading thường được ưu tiên.
	
	

# Kết luận 
	v-cloak là một cách đơn giản để ngăn chặn FOUC bằng cách ẩn nội dung chưa được biên dịch, phù hợp cho các ứng dụng Vue đơn giản. Nó yêu cầu CSS đi kèm và thường được sử dụng trong các trường hợp tải ban đầu.
