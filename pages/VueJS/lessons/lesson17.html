# Khái niệm  
	Mục đích: Khi ứng dụng Vue lớn lên, cần tổ chức code tốt hơn để dễ bảo trì, tái sử dụng và mở rộng.
	Giải pháp: Sử dụng Single-File Components (SFCs) (file .vue), kết hợp template, script, và style trong cùng một file, cùng với công cụ xây dựng như Vite.
	

	Lý do : 
		SFCs giúp tổ chức code theo component, dễ quản lý hơn. 
		File .vue không chạy trực tiếp trên trình duyệt, cần biên dịch thành HTML, CSS, JavaScript.
		
		
		
	Ví dụ file .vue: 	
		
		
<!-- App.vue -->
<template>
  <h1>{{ message }}</h1>
  <HelloWorld />
</template>

<script>
import HelloWorld from './components/HelloWorld.vue';

export default {
  data() {
    return {
      message: 'Welcome to Vue!'
    }
  }
}
</script>

<style>
h1 {
  color: blue;
}
</style>		
		
		
	Giải thích:
	<template>: Chứa HTML của component.
	<script>: Chứa logic JavaScript (dữ liệu, methods, v.v.).
	<style>: Chứa CSS, có thể thêm scoped để chỉ áp dụng cho component này.		
		
		
		
# 2. Tại sao cần SFCs và công cụ xây dựng?		
		
		
	Hạn chế của cách cơ bản : 
		Dùng <script> trong HTML (như bài templates) phù hợp cho ứng dụng nhỏ, nhưng khó quản lý khi có nhiều component. 
		Không hỗ trợ tốt các tính năng như hot-reload, tree-shaking, hoặc CSS scoped.		
		
	 	
	Lợi ích của SFCs 
		Gộp template, logic, và style vào một file, dễ đọc và bảo trì. 
		Hỗ trợ các công cụ như Vite để biên dịch, tối ưu hóa, và hot-reload. 
		
		
	Công cụ cần thiết: 
		Vite: Công cụ xây dựng nhanh, hỗ trợ SFCs và Vue 3. 
		VS Code + Volar: Trình soạn thảo và extension hỗ trợ viết file .vue. 
		
		
		
# 3. Cách thiết lập môi trường
		
	Cài đặt Vite	
		npm create vue@latest
	Tạo dự án Vue với các tùy chọn như TypeScript, Vue Router, Pinia, v.v.
	
	
	Cài VS Code và Volar: 
		Tải Visual Studio Code và cài extension Volar để hỗ trợ cú pháp Vue 3. 
	
	Chạy dự án: 
		npm install
		npm run dev
