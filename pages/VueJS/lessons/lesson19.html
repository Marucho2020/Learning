Lesson 19 -- vue Components -//


#	Khái niệm 
	Components là các khối code độc lập, tái sử dụng, bao gồm template, logic, và style, tương tự một ứng dụng Vue nhỏ.
	Mục đích: Chia nhỏ giao diện thành các phần riêng biệt (như button, header, form), dễ quản lý và tái sử dụng.
	Cách định nghĩa: Dùng app.component (global) hoặc trong file .vue (Single-File Component - SFC).

Ví dụ cơ bản (Global Component):
<div id="app">
  <my-component></my-component>
</div>

<script>
const app = Vue.createApp({});

app.component('my-component', {
  template: `<p>{{ message }}</p>`,
  data() {
    return {
      message: 'Hello from Component!'
    }
  }
});

app.mount('#app');
</script>

	Giải thích:
		app.component: Đăng ký component my-component toàn cục.
		template: HTML của component, hiển thị message.
		data: Dữ liệu reactive riêng của component.




# 2. Các đặc điểm của Components 
	
	## a. Tái sử dụng 
		Components có thể được dùng nhiều lần trong ứng dụng. Ví dụ: 
		
	<div id="app">
		<my-component></my-component>
		<my-component></my-component>
	</div>		
	
	Mỗi <my-component> là một instance độc lập với data riêng.



	## Mỗi <my-component> là một instance độc lập với data riêng.
		Components nhận dữ liệu từ component cha qua props. Ví dụ:
	
<div id="app">
  <my-component message="Hello Vue!"></my-component>
</div>

<script>
const app = Vue.createApp({});

app.component('my-component', {
  props: ['message'],
  template: `<p>{{ message }}</p>`
});

app.mount('#app');
</script>	
	
	props: ['message']: Nhận message từ thuộc tính HTML.
	
	
	##c. SFC và Components 
	Trong bài sfc_first, components được định nghĩa trong file .vue. Bài này giới thiệu cách đăng ký global components, nhưng ý tưởng tương tự. Ví dụ với SFC:
	
<!-- MyComponent.vue -->
<template>
  <p>{{ message }}</p>
</template>

<script>
export default {
  props: ['message'],
  data() {
    return {
      message: 'Default message'
    }
  }
}
</script>
