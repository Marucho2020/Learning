Lesson 5 -- Array -//


# 1. Mảng trong TypeScript là gì? 
	Mảng (array) là một danh sách các phần tử được sắp xếp theo thứ tự. Trong TypeScript, mảng được gán kiểu dữ liệu để đảm bảo tất cả phần tử trong mảng thuộc cùng một kiểu, giúp tăng tính an toàn và giảm lỗi. 
	
# 2. Khai báo mảng trong TypeScript
	TypeScript cung cấp hai cách chính để khai báo mảng:
		

	## a. Dùng type[] 
		Mô tả: Sử dụng dấu ngoặc vuông để chỉ định kiểu của các phần tử trong mảng. 
		Ví dụ : 
			let numbers: number[] = [1, 2, 3];
			let names: string[] = ["John", "Jane"];

		numbers chỉ chứa số, names chỉ chứa chuỗi. Nếu bạn thêm giá trị sai kiểu (như numbers.push("hello")), TypeScript sẽ báo lỗi.	


	## b. Dùng Array<type> 
		Mô tả: Sử dụng generic Array với kiểu dữ liệu cụ thể. 
		Ví dụ: 
			let numbers: Array<number> = [1, 2, 3];
			let names: Array<string> = ["John", "Jane"];

		Tương đương với cách type[], nhưng cú pháp này thường thấy trong các trường hợp phức tạp hơn (như generic).

		## b. Mảng hỗn hợp với Union Types 
			Nếu muốn mảng chứa nhiều kiểu dữ liệu, bạn có thể dùng union types.
			
			Ví dụ: 
				let mixed: (number | string)[] = [1, "two", 3]; 
				
				Mảng mixed có thể chứa cả số và chuỗi, nhưng không thể chứa kiểu khác (như boolean).
			


		## c. Tuple (Bộ giá trị) 
			Mô tả: Tuple là một loại mảng đặc biệt với số lượng phần tử cố định và mỗi phần tử có kiểu cụ thể.
			
			Ví dụ: 
				let person: [string, number] = ["John", 25];
				// person = [25, "John"]; // Lỗi: Sai thứ tự kiểu
				// person = ["John", 25, true]; // Lỗi: Quá nhiều phần tử		
		
				Tuple khác với mảng thông thường ở chỗ nó giới hạn số lượng và kiểu của phần tử.
				
				
		## d. Mảng chỉ đọc (Readonly Arrays)
			Mô tả: Dùng readonly để ngăn mảng bị thay đổi (thêm, xóa, hoặc sửa phần tử).
			
			Ví dụ:
				let numbers: readonly number[] = [1, 2, 3];
				// numbers.push(4); // Lỗi: Không thể thêm phần tử vào mảng chỉ đọc
		
				Cũng có thể dùng ReadonlyArray<type>
					let names: ReadonlyArray<string> = ["John", "Jane"];
		
# 4. Thao tác với mảng		
	TypeScript hỗ trợ tất cả các phương thức mảng của JavaScript (như push, pop, map, filter, v.v.), nhưng đảm bảo kiểu dữ liệu được kiểm tra.

	Ví dụ: 
let numbers: number[] = [1, 2, 3];
numbers.push(4); // OK
numbers.push("5"); // Lỗi: Không thể thêm chuỗi vào mảng số
let doubled: number[] = numbers.map(num => num * 2); // [2, 4, 6, 8]		
		
		



# 5. Type Inference (Suy luận kiểu)
	Nếu bạn khởi tạo mảng mà không khai báo kiểu, TypeScript sẽ tự suy ra kiểu dựa trên giá trị ban đầu.
	Ví dụ:
		
let numbers = [1, 2, 3]; // TypeScript suy ra: number[]
numbers.push("4"); // Lỗi: Không thể thêm chuỗi	



# 6. Tại sao mảng trong TypeScript quan trọng? 

	- Kiểm soát kiểu: Đảm bảo mảng chỉ chứa đúng kiểu dữ liệu, giảm lỗi khi thao tác.
	- Tăng tính rõ ràng: Code dễ hiểu hơn khi kiểu của mảng được định nghĩa rõ ràng.
	- Hỗ trợ công cụ: IDE như VSCode cung cấp gợi ý chính xác hơn nhờ thông tin kiểu



# 7. Ví dụ tổng hợp 	 

// Mảng số
let scores: number[] = [90, 85, 88];
scores.push(92); // OK
// scores.push("80"); // Lỗi

// Mảng hỗn hợp
let mixed: (string | number)[] = ["John", 25, "Jane", 30];

// Tuple
let employee: [string, number, boolean] = ["Alice", 30, true];

// Mảng chỉ đọc
let colors: readonly string[] = ["red", "blue"];
// colors.push("green"); // Lỗi

// Thao tác với mảng
let doubledScores: number[] = scores.map(score => score * 2);
console.log(doubledScores); // [180, 170, 176, 184]



# 8. Lưu ý thực tế 

Tuple vs Array: Dùng tuple khi số lượng và kiểu phần tử cố định (như cặp tên-tuổi). Dùng mảng thông thường khi danh sách có thể mở rộng.
Readonly: Sử dụng khi bạn muốn bảo vệ mảng khỏi bị thay đổi, đặc biệt trong các hàm nhận mảng làm tham số.
Union Types: Hữu ích khi mảng cần linh hoạt, nhưng nên giới hạn kiểu để tránh phức tạp hóa.
Type Inference: Tận dụng suy luận kiểu để giảm việc khai báo thủ công, nhưng kiểm tra kỹ để tránh lỗi không mong muốn.
