Lesson 11 -- Function -//

# 1. Hàm trong TypeScript là gì?
	Hàm trong TypeScript tương tự JavaScript, nhưng bổ sung hệ thống kiểu để định nghĩa kiểu dữ liệu cho tham số và giá trị trả về, giúp tăng tính an toàn và phát hiện lỗi sớm.


# 2. Khai báo hàm với kiểu 
	## a. Khai báo kiểu cho tham số 
	
		Mỗi tham số cần được chỉ định kiểu dữ liệu.
		Ví dụ: 
function add(a: number, b: number): number {
  return a + b;
}
console.log(add(2, 3)); // 5
// console.log(add("2", 3)); // Lỗi: Tham số đầu không phải number




	## b. Kiểu trả về (Return Type) 
		Kiểu của giá trị trả về được khai báo sau dấu : ở cuối danh sách tham số.

function greet(name: string): string {
  return `Hello, ${name}`;
}
console.log(greet("John")); // Hello, John


	## c. Hàm không trả về gì (void) 
		Dùng void khi hàm không trả về giá trị.
		
function logMessage(message: string): void {
  console.log(message);
}
logMessage("Test"); // Test


# 3. Tham số tùy chọn và mặc định

	## a. Tham số tùy chọn (Optional Parameters) 
		Thêm dấu ? để đánh dấu tham số không bắt buộc.
		
		Ví dụ:
		
function introduce(name: string, age?: number): string {
  return age ? `${name}, ${age} years old` : name;
}
console.log(introduce("John")); // John
console.log(introduce("John", 25)); // John, 25 years old

	Tham số tùy chọn phải nằm sau các tham số bắt buộc.


	## b. Tham số mặc định (Default Parameters) 
		Gán giá trị mặc định cho tham số.
		
		Ví dụ : 
		
function greet(name: string = "Guest"): string {
  return `Hello, ${name}`;
}
console.log(greet()); // Hello, Guest
console.log(greet("Jane")); // Hello, Jane



	
# 4. Rest Parameters
	Sử dụng ... để nhận số lượng tham số không giới hạn, phải khai báo kiểu mảng.

	Ví dụ: 
function sum(...numbers: number[]): number {
  return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4)); // 10		


# 5. Function Types
	Có thể định nghĩa kiểu cho hàm bằng Type Alias hoặc Interface.
	
	Ví dụ: 
	
type AddFn = (a: number, b: number) => number;
let add: AddFn = (x, y) => x + y;
console.log(add(5, 10)); // 15
	
	AddFn mô tả một hàm nhận hai tham số number và trả về number.



# 6. Ví dụ tổng hợp

// Hàm cơ bản
function multiply(a: number, b: number): number {
  return a * b;
}

// Tham số tùy chọn
function describePerson(name: string, age?: number): string {
  return age ? `${name}, ${age}` : name;
}

// Tham số mặc định
function welcome(message: string = "Hello"): string {
  return message;
}

// Rest parameters
function concat(...strings: string[]): string {
  return strings.join(" ");
}

// Function Type
type GreetFn = (name: string) => string;
let sayHi: GreetFn = (name) => `Hi, ${name}`;

console.log(multiply(2, 3)); // 6
console.log(describePerson("John")); // John
console.log(welcome()); // Hello
console.log(concat("a", "b", "c")); // a b c
console.log(sayHi("Alice")); // Hi, Alice


# 7. Lưu ý thực tế

		- Khai báo kiểu rõ ràng: Luôn định nghĩa kiểu cho tham số và giá trị trả về để tận dụng TypeScript.
		- Type Inference: TypeScript tự suy ra kiểu trả về nếu không khai báo, nhưng nên khai báo để rõ ràng.
		- Optional vs Default: Dùng tham số tùy chọn khi giá trị có thể không được cung cấp; dùng tham số mặc định khi muốn giá trị cụ thể.
		- Rest Parameters: Chỉ dùng cho danh sách tham số cuối cùng và phải có kiểu mảng.
		- Function Types: Hữu ích khi truyền hàm làm tham số hoặc lưu hàm vào biến.
