# 1. TypeScript Special Types là gì?  
	TypeScript cung cấp các kiểu đặc biệt (special types) để xử lý các tình huống phức tạp hoặc linh hoạt hơn so với các kiểu đơn giản (number, string, boolean, v.v.). Những kiểu này giúp kiểm soát chặt chẽ hoặc mở rộng khả năng định nghĩa kiểu trong code.
	


# 2. Các kiểu đặc biệt (Special Types) 
	

	## a. any 
		Mô tả: Cho phép biến nhận bất kỳ giá trị nào, bỏ qua kiểm tra kiểu tĩnh. Hữu ích khi bạn không biết trước kiểu dữ liệu (ví dụ: dữ liệu từ API bên ngoài).
		
		Ví dụ: 
let value: any = 4;
value = "hello"; // Không lỗi
value = true; // Không lỗi		

		Lưu ý: Dùng any làm mất lợi ích kiểm tra kiểu của TypeScript, nên hạn chế sử dụng.



	## b. unknown 
		Mô tả: Tương tự any, nhưng an toàn hơn. Biến kiểu unknown không thể sử dụng trực tiếp cho đến khi bạn kiểm tra hoặc ép kiểu. 
		
		Ví dụ : 
			
let value: unknown = 4;
// console.log(value.length); // Lỗi: TypeScript không biết value có .length hay không
if (typeof value === "string") {
  console.log(value.length); // OK
}

		Lưu ý: unknown buộc bạn kiểm tra kiểu, giúp code an toàn hơn so với any.




	## c. never 
		Mô tả: Biểu thị giá trị không bao giờ xảy ra, thường dùng cho hàm luôn throw lỗi hoặc vòng lặp vô hạn. 
		Ví dụ : 
			
function throwError(message: string): never {
  throw new Error(message);
}
function infiniteLoop(): never {
  while (true) {}
}

		Lưu ý: never hữu ích trong phân tích logic code, đặc biệt khi xử lý các trường hợp "không thể xảy ra".
