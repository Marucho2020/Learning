Lesson 1 -- Type Script Introduction -//

# Khái niệm 
	TypeScript là một siêu tập hợp (superset) của JavaScript, có nghĩa là nó bao gồm tất cả các tính năng của JavaScript và bổ sung thêm các tính năng mới, đặc biệt là hệ thống kiểu (type system). TypeScript được phát triển bởi Microsoft và giúp lập trình viên viết mã an toàn hơn, dễ bảo trì hơn nhờ kiểm tra kiểu dữ liệu trước khi chạy.
	
	
# 	TypeScript là gì và tại sao nên dùng?

	 TypeScript thêm các kiểu dữ liệu tĩnh (static types) vào JavaScript, giúp phát hiện lỗi sớm trong quá trình phát triển.
	 
	 Ví dụ: Bạn có thể khai báo một biến chỉ nhận giá trị string, và nếu gán một số (number) cho nó, TypeScript sẽ báo lỗi ngay trong quá trình biên dịch.
	
	
		## Lợi ích: 
			- Phát hiện lỗi sớm: Giảm lỗi runtime (lỗi khi chương trình chạy).
			- Mã dễ đọc và bảo trì: Các kiểu dữ liệu rõ ràng giúp mã dễ hiểu hơn.
			- Hỗ trợ công cụ tốt hơn: Các IDE như VS Code cung cấp gợi ý mã (autocomplete) và kiểm tra lỗi tốt hơn khi dùng TypeScript.	
	
# 	Cú pháp cơ bản
	
	
	let message: string = "Hello, World!";
	
			- Ở đây, message được khai báo là kiểu string, nên chỉ có thể gán chuỗi.
	
	
	## Các kiểu dữ liệu cơ bản trong TypeScript: 
		
			- string: Chuỗi ký tự.
			- number: Số (bao gồm cả số nguyên và số thực).
			- boolean: true hoặc false.
			- array: Mảng, ví dụ: let numbers: number[] = [1, 2, 3];.
			- any: Bất kỳ kiểu dữ liệu nào (khi không muốn kiểm tra kiểu).	
	
	
	
# Cài đặt và sử dụng TypeScript 
		
	Để sử dụng TypeScript, bạn cần cài đặt nó qua Node.js bằng lệnh 
		npm install -g typescript
		
	Sau khi viết mã TypeScript (file .ts), bạn cần biên dịch nó thành JavaScript (file .js) bằng lệnh:
		tsc filename.ts
		
		File .js sau khi biên dịch có thể chạy trên trình duyệt hoặc Node.js.
	
	
	
# Ví dụ minh họa	
	
	Bài viết đưa ra một số ví dụ đơn giản, như
	
function greet(name: string): string {
    return "Hello, " + name;
}
console.log(greet("Alice")); // Kết quả: Hello, Alice
	
	Trong hàm greet, tham số name được khai báo là kiểu string, và hàm trả về một giá trị kiểu string.
	
	
# 	Các tính năng khác
	
	## Interfaces: Cho phép định nghĩa cấu trúc của một đối tượng.
	
interface Person {
    name: string;
    age: number;
}
let user: Person = { name: "Alice", age: 25 };
	
	Classes: TypeScript hỗ trợ lập trình hướng đối tượng với các lớp và kế thừa.
	Modules: Cho phép tổ chức mã thành các module để tái sử dụng.
	
	
	
# Điểm nổi bật 
		
	- Tương thích với JavaScript: Mọi mã JavaScript đều là mã TypeScript hợp lệ. Bạn có thể chuyển đổi dự án JavaScript sang TypeScript dần dần.
	
	- Cộng đồng lớn: TypeScript được sử dụng rộng rãi trong các framework như Angular, React, và Vue.js.
