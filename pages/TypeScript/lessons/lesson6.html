Lesson 6 -- Tuple -//


# 1. Tuple trong TypeScript là gì? 
	Tuple là một kiểu dữ liệu đặc biệt của mảng trong TypeScript, cho phép định nghĩa một mảng với số lượng phần tử cố định và mỗi phần tử có kiểu dữ liệu cụ thể. Không giống mảng thông thường (có thể mở rộng và chứa cùng kiểu dữ liệu), tuple giới hạn số phần tử và cho phép các kiểu khác nhau.

		
# 	2. Khai báo Tuple 	
		
	## Cú pháp: let tênBiến: [kiểu1, kiểu2, ...]; 
	##  Ví dụ : 
		 let person: [string, number] = ["John", 25];
		 
			person là một tuple với hai phần tử: phần tử đầu tiên là string (tên), phần tử thứ hai là number (tuổi).
			Lưu ý: Thứ tự và số lượng phần tử phải khớp với khai báo.
		
# 3. Đặc điểm của Tuple		
		
		
	## a. Số lượng và kiểu cố định 
		Tuple yêu cầu đúng số lượng phần tử và đúng kiểu theo thứ tự đã khai báo. 
		
let person: [string, number] = ["John", 25]; // OK
// let person: [string, number] = [25, "John"]; // Lỗi: Sai thứ tự kiểu
// let person: [string, number] = ["John", 25, true]; // Lỗi: Quá nhiều phần tử
		
		
		
		
	## 	b. Truy cập phần tử 
		Phần tử trong tuple được truy cập bằng chỉ số (index) như mảng.
		
let person: [string, number] = ["John", 25];
let name: string = person[0]; // "John"
let age: number = person[1]; // 25
// let invalid = person[2]; // Lỗi: Tuple chỉ có 2 phần tử		
		
		
		
		
	## 	c. Tuple với Optional Elements 
		TypeScript cho phép khai báo phần tử tùy chọn trong tuple bằng dấu ?.
		
let person: [string, number, boolean?] = ["John", 25]; // OK
person = ["John", 25, true]; // OK		
		
		
		
	## 	d. Tuple với Rest Elements
		Có thể dùng ... để cho phép một số lượng phần tử không giới hạn ở cuối tuple, nhưng tất cả phải cùng kiểu.
		
		let list: [string, ...number[]] = ["scores", 90, 85, 88];
	
			Phần tử đầu là string, các phần tử còn lại là number.
	
	## e. Readonly Tuple
		Dùng readonly để ngăn tuple bị thay đổi.
	
let point: readonly [number, number] = [10, 20];
// point[0] = 5; // Lỗi: Không thể sửa tuple chỉ đọc
	
	
	
	
	
	
	
# 	4. Tuple vs Mảng 
	
	Mảng: Linh hoạt, không giới hạn số phần tử, tất cả phần tử cùng kiểu (hoặc dùng union types).
		let numbers: number[] = [1, 2, 3, 4]; // Có thể thêm/xóa phần tử
	
	
	Tuple: Cố định số lượng phần tử, mỗi phần tử có thể có kiểu riêng 	
		let person: [string, number] = ["John", 25]; // Không thể thêm/xóa

# 5. Ứng dụng của Tuple

	Biểu diễn dữ liệu có cấu trúc cố định: Ví dụ, một cặp [tên, tuổi] hoặc [x, y] cho tọa độ.

	Trả về nhiều giá trị từ hàm: 
		
function getUser(): [string, number] {
  return ["John", 25];
}
let [name, age] = getUser(); // Destructuring
console.log(name, age); // John, 25

	API hoặc dữ liệu phức tạp: Tuple giúp đảm bảo cấu trúc dữ liệu chính xác.




# 6. Ví dụ tổng hợp 
	
// Tuple cơ bản
let employee: [string, number, boolean] = ["Alice", 30, true];

// Tuple với optional element
let car: [string, number, string?] = ["Toyota", 2020];
car = ["Honda", 2021, "red"]; // OK

// Tuple với rest elements
let scores: [string, ...number[]] = ["Math", 90, 85, 88];

// Readonly tuple
let point: readonly [number, number] = [5, 10];
// point[0] = 15; // Lỗi

// Destructuring tuple
let [empName, empAge, isActive] = employee;
console.log(empName, empAge, isActive); // Alice, 30, true

# 7. Lưu ý thực tế

Khi nào dùng tuple?: Dùng khi bạn cần một danh sách có số lượng và kiểu phần tử cố định, như tọa độ, thông tin người dùng, hoặc giá trị trả về từ hàm.
Tránh lạm dụng: Nếu danh sách có thể mở rộng hoặc không có cấu trúc cố định, hãy dùng mảng thay vì tuple.
Readonly: Sử dụng khi cần bảo vệ tuple khỏi bị sửa đổi, đặc biệt khi truyền qua hàm.
Kiểm tra lỗi: Luôn khai báo kiểu rõ ràng để TypeScript phát hiện lỗi sai thứ tự hoặc số lượng phần tử.
