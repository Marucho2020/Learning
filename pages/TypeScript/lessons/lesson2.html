Lesson 2 -- Get Started -//

# 	1. Yêu cầu trước khi bắt đầu 
	Node.js: Bạn cần cài đặt Node.js vì TypeScript được cài đặt và quản lý thông qua npm (Node Package Manager).
	
	Hướng dẫn:
		Tải và cài đặt Node.js từ trang chính thức: https://nodejs.org/.
		Kiểm tra cài đặt bằng lệnh
	
node -v
npm -v



# 2. Cài đặt TypeScript 
TypeScript được cài đặt thông qua npm bằng lệnh sau:

	npm install -g typescript

	-g: Cài đặt TypeScript toàn cục (globally), cho phép sử dụng lệnh tsc (TypeScript Compiler) ở bất kỳ đâu trong terminal.

	Kiểm tra cài đặt TypeScript bằng lệnh:
		tsc -v
		
	Nếu hiển thị phiên bản (ví dụ: Version 5.x.x), TypeScript đã được cài đặt thành công.	



# 3. Viết chương trình TypeScript đầu tiên

	## Tạo file TypeScript 
		Tạo một file với đuôi .ts, ví dụ: hello.ts.
		
		Viết mã TypeScript đơn giản, như:

function greet(name: string) {
    return "Hello, " + name;
}
console.log(greet("World"));

	
	## Trong ví dụ này 
		Hàm greet nhận một tham số name kiểu string và trả về một chuỗi.
console.log in ra kết quả: Hello, World.
	
	
	## Biên dịch file TypeScript 
		TypeScript không chạy trực tiếp trên trình duyệt hoặc Node.js. Bạn cần biên dịch file .ts thành file JavaScript (.js) bằng lệnh:
			tsc hello.ts
			
			
		Lệnh này tạo ra file hello.js với nội dung tương đương bằng JavaScript:
function greet(name) {
    return "Hello, " + name;
}
console.log(greet("World"));
		
		
	File .js này có thể chạy bằng Node.js


# 4. Chạy TypeScript mà không cần biên dịch thủ công	
	
	Để tiện lợi hơn, bạn có thể sử dụng công cụ như ts-node để chạy trực tiếp file TypeScript mà không cần biên dịch thủ công:
	
	Cài đặt ts-node
		npm install -g ts-node
		
	Chạy file TypeScript
		ts-node hello.ts
		
		Kết quả tương tự: Hello, World.
	
# 	5. Cấu hình TypeScript (tsconfig.json)
	
	Khi làm việc với các dự án lớn, bạn có thể tạo file tsconfig.json để cấu hình cách TypeScript biên dịch.
	
	Tạo file tsconfig.json bằng lệnh:
		tsc --init
	
	File tsconfig.json chứa các tùy chọn như:
		target: Phiên bản JavaScript đầu ra (ví dụ: ES6).
		outDir: Thư mục lưu file .js sau khi biên dịch.
		strict: Bật chế độ kiểm tra kiểu nghiêm ngặt.	
	
	Ví dụ cấu hình cơ bản
	
{
  "compilerOptions": {
    "target": "es6",
    "outDir": "./dist",
    "strict": true
  }
}	
	
	Sau khi có tsconfig.json, bạn chỉ cần chạy tsc để biên dịch toàn bộ dự án


	
# 	6. Sử dụng TypeScript trong trình duyệt

	Để chạy TypeScript trong trình duyệt, bạn cần:
	
		Biên dịch file .ts thành .js.
		Nhúng file .js vào file HTML
	
<!DOCTYPE html>
<html>
<body>
    <script src="hello.js"></script>
</body>
</html>

Mở file HTML trong trình duyệt để xem kết quả.


# 7. Công cụ hỗ trợ

IDE/Editor: Bài viết khuyến nghị sử dụng các trình soạn thảo như Visual Studio Code, vì nó có hỗ trợ tích hợp tốt cho TypeScript (gợi ý mã, kiểm tra lỗi, v.v.).
Live Server: Để chạy file HTML dễ dàng, bạn có thể cài extension như Live Server trong VS Code để xem kết quả trực tiếp khi thay đổi mã.
