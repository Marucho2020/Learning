Lesson 28 -- Buffer -//


# 1. Buffer là gì? Tại sao cần nó?

	-Trong browser JavaScript: chỉ làm việc với chuỗi (string), không có cách xử lý dữ liệu nhị phân (binary) trực tiếp.
	-Trong Node.js: bạn phải đọc file, nhận dữ liệu từ mạng, xử lý ảnh, video, mã hóa… → cần làm việc với dữ liệu thô (raw binary).
	-Buffer chính là mảng các byte (0-255) được cấp phát ngoài V8 heap → nhanh, không bị garbage collector quấy rầy.

	Buffer = Array của số nguyên 0-255, đại diện cho 1 đoạn bộ nhớ thô.

	Buffer là global, không cần require():

const buf = Buffer.from('Hello');
console.log(buf); // <Buffer 48 65 6c 6c 6f>



# 2. 3 cách tạo Buffer (QUAN TRỌNG NHẤT)

	1. Buffer.alloc(size),
	Rất an toàn,
	Luôn dùng khi tạo buffer mới
	
	
	2. Buffer.allocUnsafe(size),
	Không an toànRất nhanh,
	Chỉ dùng khi cần tốc độ cực cao và bạn sẽ ghi đè ngay
	
	
	3. Buffer.from(data),
	An toàn,Nhanh,
	"Tạo từ string, array, buffer khác"
	

	## Ví dụ thực tế:

// 1. An toàn nhất - luôn dùng cái này khi bắt đầu
const buf1 = Buffer.alloc(10);        // 10 byte = 0
// 2. Nhanh nhưng nguy hiểm (có thể chứa dữ liệu cũ)
const buf2 = Buffer.allocUnsafe(10);  // có thể chứa password cũ của ai đó!
// 3. Từ dữ liệu có sẵn
const buf3 = Buffer.from('Xin chào'); // UTF-8
const buf4 = Buffer.from([65,66,67]); // ABC

	Lời khuyên chuyên gia: 99% trường hợp dùng Buffer.alloc() hoặc Buffer.from(). Chỉ dùng allocUnsafe trong server siêu cao tải và bạn chắc chắn sẽ ghi đè toàn bộ.



# 3. Đọc & Ghi Buffer


const buf = Buffer.alloc(20);

buf.write('Hello');        // ghi từ vị trí 0
buf.write('World', 6);     // ghi từ vị trí 6
console.log(buf.toString()); // "Hello World"

// Ghi từng byte
buf[0] = 72; // 'H' trong ASCII


	## Đọc từng phần

const buf = Buffer.from('Node.js rất hay!');

console.log(buf.toString());           // toàn bộ
console.log(buf.toString('utf8', 0, 4)); // "Node"
console.log(buf[0]);                   // 78 (byte đầu)





# 4. Các phương thức hay dùng


| Phương thức                                             | Mô tả                       | Ví dụ                  |
| ------------------------------------------------------- | --------------------------- | ---------------------- |
| `buf.toString([encoding], [start], [end])`              | Chuyển buffer → string      | `buf.toString('hex')`  |
| `Buffer.concat(list, [totalLength])`                    | Nối nhiều buffer            | `Buffer.concat([a,b])` |
| `buf.slice(start, end)`                                 | Cắt buffer (cùng vùng nhớ!) | `buf.slice(0,5)`       |
| `buf.copy(target, targetStart, sourceStart, sourceEnd)` | Copy dữ liệu                | —                      |
| `buf.equals(other)`                                     | So sánh nội dung            | —                      |
| `buf.indexOf(value)`                                    | Tìm vị trí byte hoặc chuỗi  | `buf.indexOf('Node')`  |


	Cảnh báo slice: slice không copy mà trỏ cùng vùng nhớ → sửa slice sẽ sửa luôn buffer gốc!


const orig = Buffer.from('Hello');
const slice = orig.slice(0,3); // "Hel"
slice[0] = 88; // 'X'
console.log(orig.toString()); // "Xello" ← bị thay đổi!




# 5. Encoding (Mã hóa) - Siêu quan trọng


const str = 'Xin chào';

// String → Buffer
const utf8 = Buffer.from(str, 'utf8');
const base64 = utf8.toString('base64');
console.log(base64); // "WGluIGNow6Bv"

// Buffer → String
const back = Buffer.from(base64, 'base64').toString('utf8');
console.log(back); // "Xin chào"


	## Các encoding hay gặp: 
	
		utf8 (mặc định)
		hex (mỗi byte → 2 ký tự hex)
		base64 (dùng trong email, JWT)
		ascii, latin1

#7. Bảo mật - ĐIỀU QUAN TRỌNG NHẤT khi đi làm

	1.Không dùng allocUnsafe nếu không cần thiết
	2. Xóa dữ liệu nhạy cảm ngay sau khi dùng


function hashPassword(pw) {
  const buf = Buffer.from(pw);
  const hash = require('crypto').createHash('sha256').update(buf).digest('hex');
  
  buf.fill(0); // XÓA MẬT KHẨU KHỎI BỘ NHỚ
  return hash;
}


# 8. Tối ưu hiệu năng (dành cho senior)

// Buffer pool cho server nhận hàng nghìn request/giây
class FastBufferPool {
  constructor(size, count) {
    this.size = size;
    this.pool = [];
    for (let i = 0; i < count; i++) {
      this.pool.push(Buffer.allocUnsafe(size));
    }
  }
  get() { return this.pool.pop() || Buffer.allocUnsafe(this.size); }
  release(buf) { buf.fill(0); this.pool.push(buf); }
}
