# NPM là gì?
	NPM là trình quản lý gói cho Node.js, cho phép bạn:

		- Cài đặt các package (thư viện hoặc module) từ kho lưu trữ trực tuyến tại npmjs.com, nơi chứa hàng triệu package miễn phí.
		- Quản lý các phụ thuộc (dependencies) của dự án.
		- Chạy các script để tự động hóa task (như build, test).

Khi bạn cài đặt Node.js, NPM được cài tự động, sẵn sàng sử dụng qua command line interface (CLI).



# Package là gì?

	Trong Node.js:

		- Package: Là một bộ sưu tập các file (thường là JavaScript) tạo nên một module (thư viện).
		- Module: Là code JavaScript có thể import vào dự án để sử dụng các chức năng được đóng gói sẵn (e.g., xử lý string, tạo server).

	Ví dụ: Package upper-case cung cấp hàm để chuyển đổi chuỗi thành chữ hoa. Package có thể chứa:

		Code chính (JavaScript).
		Metadata (trong package.json).
		Các phụ thuộc khác (dependencies).



# Cài đặt Package

	Để cài đặt một package, bạn dùng lệnh npm install (hoặc npm i) trong CLI.

	Ví dụ: Cài đặt package upper-case
		npm install upper-case

	Cấu trúc thư mục sau khi cài:
		C:\Users\YourName\project\node_modules\upper-case

	NPM cũng cập nhật file package.json (nếu có) để ghi lại phụ thuộc.
	Insight: Thư mục node_modules chứa tất cả package và phụ thuộc của chúng. Nó có thể trở nên rất lớn trong dự án phức tạp, vì vậy luôn thêm node_modules vào .gitignore khi dùng Git
	

# Sử dụng Package

	## Ví dụ: demo_uppercase.js
	
const http = require('http');
const uc = require('upper-case');

http.createServer(function (req, res) {
  res.writeHead(200, { 'Content-Type': 'text/html' });
  res.write(uc.upperCase('Hello World!'));
  res.end();
}).listen(8080);

	Chạy file:
	node demo_uppercase.js

	require('upper-case'): Import package upper-case.
	uc.upperCase('Hello World!'): Gọi hàm upperCase để chuyển Hello World! thành HELLO WORLD!.
	Tạo server HTTP trả về chuỗi chữ hoa.


	Insight: Package như upper-case đơn giản nhưng hữu ích để xử lý string. Trong thực tế, bạn thường dùng các package phổ biến như express, lodash, hoặc axios để tăng tốc phát triển.
	
	
	
	
	
	
# Global Packages
	Package có thể được cài đặt global (toàn cục) để sử dụng như CLI tool, thay vì chỉ trong dự án cục bộ.

	npm install -g http-server

	Output: Khởi động một web server đơn giản tại thư mục hiện tại, thường chạy trên http://localhost:8080.


# Cập nhật Package
	Để giữ package luôn mới, bạn có thể cập nhật bằng các lệnh sau:

	npm update upper-case


	Cập nhật tất cả package
	npm update

	Kiểm tra package lỗi thời
	npm outdated
	
	
	
# 	Gỡ bỏ Package
	
	npm uninstall upper-case
	
	
	
# 	Tổng kết và Lời khuyên
	
NPM là công cụ cốt lõi giúp quản lý và tích hợp thư viện vào dự án Node.js. Key takeaways:

NPM: Package manager để cài đặt, cập nhật, gỡ bỏ package.
Package: Thư viện JavaScript, lưu trong node_modules.
Cài đặt: Dùng npm install <package> (local) hoặc npm install -g <package> (global).
Cập nhật: npm update và npm outdated để quản lý version.
Gỡ bỏ: npm uninstall để dọn dẹp.
