# Bước 4: Tạo Ứng Dụng Đầu Tiên (Getting Started)
	Bây giờ, thực hành: Tạo một server web đơn giản hiển thị "Hello World!".
	

let http = require('http');

http.createServer(function(req,res){
	res.writeHead(200,{'Content-Type' : 'text/html'});
	res.end('Hello World!');
});.listen(8080);


	## Giải thích code chi tiết (dòng theo dòng): 

		let http = require('http');: Import module HTTP built-in của Node.js. require là cách cũ (CommonJS); phiên bản mới dùng import (ES Modules). Module HTTP cho phép tạo server web.

		http.createServer(function (req, res) { ... });: Tạo một server. Hàm callback nhận 2 tham số:

		req (request): Thông tin từ client (trình duyệt), như URL, headers.
		
		res (response): Đối tượng để gửi phản hồi về client.
			Đây là event-driven: Server lắng nghe request và xử lý.

		res.writeHead(200, {'Content-Type': 'text/html'});: Gửi header phản hồi. 200 là status code OK. Content-Type chỉ định nội dung là HTML (dù ở đây là text plain, nhưng tài liệu dùng vậy cho đơn giản).

		res.end('Hello World!');: Kết thúc phản hồi, gửi nội dung "Hello World!" về client. Không dùng res.end sẽ treo request.
		
		.listen(8080);: Server lắng nghe trên port 8080 (port mặc định HTTP là 80, nhưng 8080 tránh xung đột). Server chạy liên tục đến khi stop (Ctrl+C).
		
		Cơ chế hoạt động: Đây là server non-blocking. Node.js dùng single-thread event loop, nên có thể xử lý nhiều kết nối mà không tắc nghẽn. Code này tạo HTTP server cơ bản, tương tự Express.js nhưng đơn giản hơn.
		
		Lưu ý an ninh: Port 8080 cần mở firewall nếu test từ máy khác. Cho local, OK.

# Bước 6: Khởi Chạy File Node.js

Chạy lệnh: node myfirst.js


	## Giải thích chi tiết:
		node: Lệnh chạy file JavaScript bằng Node.js runtime.
		Server sẽ chạy ngầm, không output gì trên terminal (trừ lỗi).
		Máy bạn giờ là server! Nó lắng nghe request trên port 8080.

	## Test ứng dụng:

		Mở browser (Chrome/Firefox).
		Truy cập: http://localhost:8080
		Bạn sẽ thấy "Hello World!".
		localhost là địa chỉ loopback (127.0.0.1), nghĩa là máy local.

		Nếu từ máy khác: Dùng IP máy bạn (ví dụ http://192.168.1.100:8080), nhưng cần config firewall.
		Stop server: Nhấn Ctrl+C trên terminal.
